## 3. 알바 상호작용 — 작업 자리 예약 → 존 안에서 자유롭게

**문제**: 알바가 존마다 1~4개인 작업 지점(`WorkSlot`)을 **예약**해야만 일할 수 있었음. 빈 슬롯이 없으면 일이 있어도 그 자리에서 멈춰 기다림 → 자리가 없어 지게차 알바 등이 일을 못 함.

| | 전 | 후 |
|---|---|---|
| 일하는 조건 | 빈 `WorkSlot`을 예약하고 **그 지점에 서야** 상호작용 | 대상 존 **사각형 안에 들어가 멈추면** 일함 (플레이어와 같음) |
| `WorkSlot` | 예약 대상 (`Owner` · `TryClaim` · `Release` · `FindNearestFree`) | **서는 위치 후보**일 뿐 (데이터 없음, 예약 삭제) |
| 인원 제한 | 슬롯 수만큼 | 없음 (재포장 테이블만 1명) |
| 존 고르기 | 가장 가까운 빈 슬롯 | 점수 = 서는 위치까지 거리 + 그 존에 가는/일하는 **같은 직무 수 × `crowdPenalty`** (몰림 분산) |
| 서는 위치 | 예약한 슬롯 자리 | 후보 중 다른 알바가 `standSpacing` 안에 가장 적은 곳 → 다 차면 둘레를 넓혀 **존 안 · 네비메시 위 · 소품 없는 빈 곳**에 비켜 섬. 존 가장자리에서 `zoneEdgeMargin` 안쪽 |
| 할 일 없을 때 | 역할 존의 빈 슬롯에서 대기 (슬롯 없으면 제자리) | **마지막 일한 존 바깥**으로 `waitOffset` 비켜 섬. 겹치면 변을 따라 `waitSpacing`씩 옆으로. 일한 적 없으면 생성 지점 근처. **대기 중엔 아무 존도 막지 않음** |
| 화물 예약 | 트럭 · 선반 빈자리 · 주문 수요 | 그대로 |

- **재포장 테이블**: 1명 제한을 슬롯 대신 `RepackTable`이 직접 함 (`Operator` · `TryClaim` · `Release` · `IsFreeFor`).
- **쓰레기장**: 존 2.4 × 2m(통 1개) → **6.4 × 2m(통 5개 앞)**. 서는 위치 후보 `WorkSlot` 5개. 쓰레기는 버린 사람에게 **가장 가까운 통**으로 날아감 (`TrashDropZone.bin` → `bins` 배열).
- 모듈 재배치: 서는 위치를 존 로컬로 들고 있어 같이 옮겨짐. 팝 연출이 끝난 뒤 다시 계산.
- 새 설정 (`StaffRules`, 모두 `임시`): `crowdPenalty` 4m, `standSpacing` 0.5m, `zoneEdgeMargin` 0.3m, `waitOffset` 0.6m, `waitSpacing` 0.6m.

**파일**: `Scripts/Staff/StaffWorker.cs`, `Scripts/Interaction/WorkSlot.cs`, `Scripts/Logistics/RepackTable.cs`, `Scripts/Logistics/TrashDropZone.cs`, `Scripts/Data/StaffRules.cs`, `Data/StaffRules.asset`, `Prefabs/Modules/Module_Trash.prefab`

- 주의: 내거의 쓰레기통 4개 개별 콜라이더는 **안 옮김** (프로젝트의 넓힌 콜라이더 수정이 이미 있음).

## 4. 파트 1 · 2 반복 — 하차 파트 · 상차 파트

| | 전 | 후 |
|---|---|---|
| 파트 번호 | 1, 2, 3, 4… 계속 증가 | **1 ↔ 2 반복** |
| 1파트 (하차) | 하차 · 상차 둘 다 | 줄의 하차 트럭이 **하차장에 들어감**. 새 상차 트럭 안 옴 |
| 2파트 (상차) | 하차 · 상차 둘 다 | **새 상차 트럭만** 옴. 하차 트럭은 줄에서 기다림 |
| HUD 시계 | `2파트 · 02:47` | `2파트 상차 · 02:47` |

- 하차 트럭 **도착 · 줄은 원래대로** (최대 3대, 20초 간격). 2파트 동안 온 트럭은 줄에 서 있다가 다음 1파트에 들어감.
- 이미 정차한 트럭은 파트가 바뀌어도 남음 (덜 내린/덜 실은 트럭 계속 작업 가능).
- 사무실 전(파트 0, 튜토리얼 앞부분)은 둘 다 들어옴.
- 판정: `PartService.InboundOpen` · `OutboundOpen` = 파트 0이거나 그 파트 진행 중.

**파일**: `Scripts/Economy/PartService.cs`, `Scripts/Logistics/InboundQueue.cs`(하차장에 넘길 때 `InboundOpen` 확인 + `Update`에서 열리면 넘김), `Scripts/Logistics/OutboundBay.cs`, `Scripts/UI/PartClockView.cs`
