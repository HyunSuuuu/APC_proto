# 앙팡물류센터 — 기능 리스트

> 프로토타입(Lv.11) 구현용 기능 정리. 원본: 기획 엑셀 `기능 리스트` 시트

## 우선순위 기준

| 우선순위 | 기준 |
|---|---|
| **1순위** | 프로토타입(Lv.11) 핵심 루프. 하차 → 보관 → 상차 → 현금 → 건설·고용이 돌아가려면 꼭 필요한 기능 |
| **2순위** | 프로토타입 완성도. 있으면 게임성 판단이 쉬워지는 기능 (저장, 업그레이드, 가이드, 일부 이벤트) |
| **3순위** | 프로토타입 이후, 또는 회의에서 아직 정하지 못한 기능 |

**회의 결정** — `확정` = 11/5 XMind 빨간색 항목, `논의 중` = 회의에서 나왔지만 미정.  
아트 에셋은 임시 박스로 대체해도 1순위 기능은 먼저 구현 가능.

## 프로토타입 1순위 체크리스트

**플레이어**
- [ ] 가상 조이스틱 이동 — 화면 드래그로 이동. 손을 떼면 정지.
- [ ] 화물 자동 집기 / 내려놓기 — 하차 지점·선반 범위에 들어가면 일정 간격으로 한 개씩 자동으로 집거나 내려놓음 (버거 플리즈식).
- [ ] 머리 위 max 표시 — 들고 있는 상자를 위로 쌓아 보여주고. 최대 적재 수 도달 시 'MAX' 표시.
- [ ] 상호작용 존 감지 — 패드·데스크·검수대 위에 서면 트리거. 머무는 동안 게이지가 차고, 다 차면 동작 실행.

**카메라**
- [ ] 플레이어 추적 — 기본 상태에서 플레이어를 부드럽게 따라감 (쿼터뷰 고정 각도).
- [ ] 자유 이동 (플레이어와 분리) — 드래그로 맵을 둘러보고 핀치로 확대·축소.

**물류 흐름**
- [ ] 화물 종류 / 상태 — 화물은 종류(초기 2종), 소속 회사, 상태(일반 / 반품)를 가짐. 크기는 모두 같음
- [ ] 입고 차량 도착 · 정차 — 차량이 도로를 따라 들어와 빈 주차장에 정차. 하차가 끝나면 출발. 동시 정차 수 = 주차장 수.
- [ ] 하차 화물 생성 — 정차한 차량의 화물을 하차 지점에 알바가 하나씩 쌓음. 플레이어·알바가 여기서 집어감.
- [ ] 선반 적재 / 꺼내기 — 선반마다 용량(기본 10) 보유. 넣을 때 +1, 꺼낼 때 -1. 시작 시 4개 배치
- [ ] 선반 적재 단계 표현 — 적재량 비율에 따라 빈 / 절반 / 가득 외형으로 교체.
- [ ] 상차 적재 → 출고 — 상차 패드에 화물을 놓으면 출고 차량에 실림. 차량이 가득 차면 출발
- [ ] 반품 처리 루프 — 반품 상자 → 검수 테이블에서 검수 → 반품 랙 보관 → (재포장 후) 재출고. Lv.11 해금.

**경제 / 건설**
- [ ] 부지 확장 — 잠긴 칸을 해금하면 바닥·벽 모듈이 이어 붙으며 부지가 넓어짐. 섬처럼 떨어지지 않음.

**알바생**
- [ ] 알바 고용 — 고용 데스크에서 고용 비용을 내고 알바 생성.
- [ ] 역할별 작업 루프 — 배정된 역할(하차 / 보관 / 상차)에 따라 '이동 → 집기 → 운반 → 내려놓기'를 반복하는 상태 머신.
- [ ] 경로 탐색 — 네비로 목적지까지 이동. 알바끼리는 충돌 없이 겹쳐 지나감.
