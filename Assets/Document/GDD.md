## 1. 게임 개요

### 1.1 한 줄 소개

작은 물류센터의 신입 센터장이 되어 택배를 직접 나르고, 주문을 처리해 번 돈으로 알바생을 고용하고 레벨업으로 구역을 늘려 센터를 자동화하는 **캐주얼 물류 경영 아케이드**.

### 1.2 기본 정보

| 항목 | 내용 |
|---|---|
| 장르 | 하이브리드 캐주얼 · 아케이드 경영 (자동 집기/내려놓기 방식) |
| 플랫폼 | 모바일 (Android / iOS) |
| 화면 방향 | **가로 고정** |
| 엔진 | Unity 6000.3 |
| 시점 | 쿼터뷰 고정 각도 3D |
| 아트 톤 | 귀여운 SD 캐주얼 — 2~3등신 캐릭터, 로우폴리 파스텔 톤. 작은 물류센터가 점점 커지는 성장 판타지 |
| 프로토타입 아트 | 임시 박스/프리미티브로 대체 가능. 화물 구분용 **테이프 색상**만은 처음부터 적용 |

### 1.3 프로토타입 목표

- **진행 목표**: Lv.1에서 시작해 **Lv.5**까지 간다. Lv.5는 프로토타입에서 보여 줄 기능(색 분류 · 반품 재포장 · 쓰레기 · 구루마 · 롤테이너 · D 구역 가구 상자 · 지게차 알바 · 선반 단계 · 트럭 3단계)이 모두 들어 있는 레벨이다. 이후 종료 조건 없이 계속 플레이. `확정` (2026-11-15, 2026-11-18 기획 타임라인 반영)
- **기획 타임라인** (`Document/타임라인.xmind`, 2026-11-18): 미션을 하나씩 깨며 지폐 발판이 하나씩 열리는 진행이지만, 표 · 수치가 정해지지 않아 **프로토타입은 레벨 제도를 유지**하고 레벨마다 열리는 순서만 타임라인에 맞춘다 (10.3). 타임라인에서 가져온 것 = **빈 땅에서 건물 세우기로 시작**(9.6) · **책상 A · B 역할**(4.3) · **선반 단계 6 → 9 → 12**(7.3, 모양 변화는 취소) · **트럭 3단계**(7.1). 나머지(휴게실 · 하차 5 · 상차 4 · 센터 확장 · 반품 · 지게차 2단계 · 지역 2 · 미션 진행)는 백로그(17) `확정`
- '프로토타입 완료' 표시는 **삭제**한다 (변경사항 2). `확정`
- **목표 플레이 시간**: 목표 달성까지 약 25~35분 `임시`

### 1.4 검증 질문

프로토타입 플레이 테스트에서 아래 질문에 답할 수 있어야 한다.

| # | 검증 질문 | 확인 방법 |
|---|---|---|
| 1 | 화물을 자동으로 집고 쌓아 나르는 **손맛**이 기분 좋은가? | 집기 간격·스택 연출 조정 전후 비교 |
| 2 | 흐름(하차 → **색 맞춰 보관** → 상차)이 **복잡하지 않고** 이해되는가? | 튜토리얼 없이/있이 첫 상차 트럭 출발까지 걸린 시간 |
| 3 | 알바를 고용해 **직접 하던 일이 자동화되는 쾌감**이 Lv.5까지 이어지는가? | 레벨별 플레이어 운반 비율 |
| 4 | **빈 구역 짓기 · 설비(구루마 · 롤테이너 · 지게차)** 가 다음 목표로 느껴지는가? | 레벨업 → 그 레벨 건설 타일 완성까지 걸린 시간 |
| 5 | 성장 속도(레벨업·재화)가 너무 빠르거나 느리지 않은가? | 레벨별 도달 시간 로그 |
| 6 | **저금통 → 파트타임 정산** 구조가 "모아서 한 번에 받는" 기대감을 주는가? 월급 부담이 적절한가? | 파트별 정산액, 미지급 · 퇴사 발생 횟수 |

### 1.5 디자인 필러

1. **손으로 나르는 재미** — 모든 물류는 플레이어가 직접 해볼 수 있고, 자동 집기와 스택 연출이 기분 좋아야 한다.
2. **눈에 보이는 성장** — 구역이 늘고, 선반과 저금통이 차고, 알바가 늘어나는 변화가 화면에서 바로 보인다.
3. **한 단계씩 늘어나는 흐름** — 처음에는 단순한 흐름에서 시작해 레벨마다 단계(새 색 트럭, 반품 재포장 · 쓰레기, 전자제품 · 구루마, 정전, 가구 · 지게차)가 하나씩 추가된다.

## 2. 핵심 루프

### 2.1 사이클 (상차 트럭 1대 = 수익 1회)

`확정` (2026-11-15, 변경사항 2 — 계약 → 색 트럭 웨이브)

```
[트럭 웨이브]  레벨이 되면 그 색 트럭이 웨이브에 합류 (그 색 보관 구역이 있어야 옴)
   │
   ▼
① 하차    하차 트럭이 하차 칸에 후진 주차 → 트렁크 문이 열림
          → 플레이어 / 하차 알바가 꺼내 하차 칸 '상자 두는 공간'(최대 10)에 쌓음
② 보관    상자를 **같은 색 보관 구역** 선반에 넣음 (다른 색 구역 · 다른 곳은 '넣을 수 없음')
③ 상차    상차 트럭 위 게이지(색상별 필요 개수)를 보고 선반에서 꺼내 실음
          → 다 차면 문을 닫고 **돈을 두고** 떠남 → 다음 트럭이 바로 들어옴
   │
   ▼
[돈 더미]  상차 칸 '돈 떨어지는 공간'에 쌓임 → 지나가며 줍기 → **사무실 투명 저금통**
   │
   ▼
[파트타임 정산]  파트(3분)가 끝나면 저금통 → 지갑, 알바 월급 지급 → 지갑 돈으로 짓기 · 고용 · 업그레이드
   │
   ▼
[레벨업]  새 색 트럭 합류 + 건설 타일(빈 구역 짓기 · 칸 늘리기) → XP → … → Lv.5
```

- **포장은 일반 주문에 없다**. 포장대는 반품 재포장에만 쓴다 (→ 7.7).
- **Lv.2~**: B(초록) 트럭 합류 · 하차 칸 2 · **반품 구역** — 반품 구역을 지은 뒤 모든 트럭에 찌그러진 상자가 섞인다 → 반품 팔레트 → 재포장 테이블 → (70%) 같은 색 보관 구역, 재포장 쓰레기는 쓰레기장으로 (2026-11-17 저녁, 검수 삭제).
- **Lv.3~**: C(파랑) 전자제품, 구루마. **Lv.4~**: 상차 칸 2 · 롤테이너 · 하차 트럭 2단계 (정전 삭제 2026-11-18). **Lv.5~**: D(보라) 가구 큰 상자 — 지게차로만.
- **돈은 바로 쓰지 않는다**: 주운 돈은 저금통에 모이고, 파트타임 정산 때 지갑으로 옮겨져야 쓸 수 있다 (→ [9.5](#95-저금통--파트-종료-정산-1순위)). `확정` (2026-11-15)

### 2.2 루프 계층

| 계층 | 주기 | 내용 |
|---|---|---|
| 마이크로 | 수 초 | 존에 들어가 자동으로 집기/내려놓기, 건설 타일 게이지 채우기 |
| 메인 | 30초~1분 | 상차 트럭 1대 채우기 → 돈 줍기 → 저금통 |
| 파트 | 3분 고정 `임시` | 파트가 끝나면 정산 팝업: 번 돈(저금통) − 알바 월급 → 지갑 → [9.5](#95-저금통--파트-종료-정산-1순위) |
| 메타 | 2~4분 | 레벨업 → 빈 구역 짓기 · 칸 늘리기 · 고용 · 업그레이드 → 처리량 증가 |

## 3. 조작 · 카메라

### 3.1 이동 — 가상 조이스틱 `1순위`

- **플로팅 조이스틱**: UI가 아닌 화면 아무 곳이나 터치하면 그 자리에 조이스틱이 생기고, 드래그한 방향으로 이동한다.
- 손을 떼면 즉시 정지하고 조이스틱이 사라진다.
- 드래그 거리 50% 미만은 걷기, 이상은 뛰기 애니메이션 (속도는 입력 크기에 비례).
- 최대 드래그 반경 80px `임시`

### 3.2 카메라 `1순위`

| 모드 | 동작 |
|---|---|
| **추적 (기본)** | 쿼터뷰 고정 각도(Pitch 45° `임시`, Yaw 45° `확정`)로 플레이어를 부드럽게 따라감 (감쇠 0.15초 `임시`) |
| **자유 이동** | HUD의 **카메라 버튼**으로 진입. 한 손가락 드래그로 맵 이동, 핀치로 확대·축소. **CCTV는 만들지 않는다** `확정` |

- 자유 모드에서는 조이스틱이 꺼지고, 카메라 버튼이 **'내 캐릭터로'** 버튼으로 바뀐다. 누르면 플레이어 위치로 0.4초 동안 부드럽게 복귀한다. `확정`
- 줌 범위: 카메라 거리 12~30, 기본 18 `임시`
- **이동 범위 제한** `2순위`: 해금된 부지 경계 밖으로 카메라가 나가지 않는다. 부지를 확장하면 경계도 함께 넓어진다.

## 4. 맵 · 레이아웃

### 4.1 원칙

- 배치는 **(행, 열)** 로 부른다. 부지는 **가로 6 × 세로 4** 칸, 왼쪽 위가 (1,1). `확정` (2026-11-14, 키패드 번호 표기 폐기)
- **하차 칸**(하차장 모듈)은 트럭에서 꺼낸 상자를 두는 **'상자 두는 공간'**(최대 10 `임시`, 옛 공용 보관소 팔레트)을 각자 가진다. **상차 칸**(상차장 모듈)은 **'돈 떨어지는 공간'** 을 가진다. `확정` (2026-11-15) — 기능리스트의 상차 칸 '상자 갖고 가는 공간'은 **만들지 않는다** (선반 → 상차 트럭 직접). `확정` (2026-11-16)
- Lv.1은 하차 · 상차 칸 **1개씩**이다. 칸을 늘리면(건설 타일) 동시에 들어오는 트럭이 늘고, 짓는 동안에도 원래 칸은 그대로 쓴다. `확정`
- 하차장 · 상차장 모듈은 **가장자리용**이다. 주차장은 모듈 칸 **바깥 가장자리에 붙어 있고**, 트럭은 주차장 바깥에 나타나 **후진으로 곧장** 들어온다 (앞머리는 바깥쪽, 뒷문은 건물 쪽). 나중에 모델이 들어오면 건물 벽의 **슬라이드 도어**에 트럭 화물칸 문만 보이게 붙는다. `확정`
- 트럭 방향: 하차 (4,2) = 왼쪽에서, 하차 (3,1) = 아래에서, 상차 (2,4) = 오른쪽에서, 상차 (3,5) · (3,6) = 위에서. `확정` (2026-11-14)
- 하차 · 상차 존은 트럭 뒷문 앞(모듈 안, 가장자리 쪽 끝)에 있다.
- 부지는 **모듈**(n × m 칸 프리팹)을 config(`SiteLayout`)에 적힌 위치 · 해금 레벨대로 붙여 만든다 (→ TechStack 5.7). 확장 = 잠긴 칸에 모듈을 붙이는 것.
- **잠긴 칸은 들어갈 수 없다.** 플레이어 · 알바는 열린 칸 안에서만 움직인다 (가장자리에서는 벽을 따라 미끄러짐).
- 모듈은 **초기 모듈**(게임 시작 때 있음)과 **해금 모듈**(건설 타일에 돈을 채워 지으면 생김) 두 종류다. `확정` (2026-11-13)
- 해금 모듈은 **레벨 + 돈**으로 연다: 해금 레벨이 되면 그 칸에 **건설 타일**(옛 해금 발판, 구매 패드 → 9.2)이 팝 연출과 함께 나타나고, 플레이어가 건설 타일에 지갑 돈을 다 채우면 구역이 팝 연출과 함께 **뿅 나타난다** (+ XP +3). 레벨 전에는 건설 타일이 보이지 않는다. 기능리스트 용어로 '해방', 이 문서에서는 '해금'을 그대로 쓴다. `확정` (2026-11-15)
- **다음 해금 레벨의 잠긴 칸 모두** 공사장 가설 울타리와 표지(`잠금해제 : LV 3`, 칸마다)로 보여준다. 레벨이 되면 울타리가 건설 타일로 바뀐다. `확정` (2026-11-17)
- 부지 바깥 바닥(초록 Ground)은 임시이며 나중에 지운다.
- 확장 칸은 이미 열린 칸과 붙어 있어야만 해금된다 (섬처럼 떨어진 칸 없음).
- 여러 칸을 **한 번에 해금되는 묶음**으로 만들 수 있다. 예: 선반 구역 모듈 + 옆의 **빈 타일**(바닥만 있는 칸)을 묶으면 ㄱ자 구역이 한꺼번에 열린다. 묶음은 대표 칸의 해금 레벨을 쓴다. `확정`

### 5.2 상호작용 존 `1순위`

존은 두 종류다. 모든 존은 바닥 마킹으로 표시한다.
- **바뀜** (2026-11-17): 바닥 판(패드) · 바닥 글자 · 바닥 원형 게이지를 **삭제**한다. 존 영역은 에디터 기즈모로만 확인한다. 게이지는 사무실 책상 2종(고용 · 업그레이드) · 반품 재포장 테이블에서 **플레이어 머리 위 가로 막대**로 찬다. **확장 패드는 보류** (나중에 바닥 UI로 바꿈) `확정`

| 종류 | 동작 | 해당 존 |
|---|---|---|
| **운반 존** | 존 안에 있는 동안 간격마다 1개씩 자동으로 집거나 내려놓음 | 하차 트럭 뒷문, 하차 칸 상자 두는 공간, 선반 둘레 존, 상차 트럭 뒷문, 반품 선반, 쓰레기 더미 · 쓰레기장 (+ 돈 더미 · 금은 지나가기만 해도 흡수하는 예외) |
| **게이지 존** | 존 위에 서 있으면 게이지가 차고, 다 차면 동작 실행 | 건설 타일, 재포장 테이블 |
| **메뉴 존** | 앞에 멈추면 메뉴가 열림 | 클립보드 책상, 컴퓨터 책상 |

- 운반 존 일부는 **컨베이어 벨트의 Start · End**가 될 수 있다 (7.10). 벨트 위 물건은 상호작용할 수 없다. `확정` (2026-11-23)

- `확정` (2026-11-15, 변경사항 2): 상호작용 대상 = 클립보드 책상 · 컴퓨터 책상 · 건설 타일 · 검수 테이블 · 포장대 · 돈 더미. **게이지는 건설 타일에서만 찬다**고 적혀 있으나, 재포장 · 분전반 진행 표시도 게이지로 둔다 `임시`.

- **상호작용은 존 안에서 멈춰 있을 때만 일어난다.** 움직이면 즉시 멈춘다. 지나가다 실수로 구매·하차하는 일을 막는다. `확정`
  - **운반 존**: 멈춘 뒤 0.5초 `임시`가 지나면 첫 상자를 바로 옮기고, 이후 간격마다 1개씩. 대기 중에는 존 바닥 색이 점점 밝아진다.
  - **게이지 존**: 따로 기다리지 않고 **멈추는 순간부터 게이지가 찬다** (게이지가 곧 대기 시간). 사무실 책상(클립보드 · 컴퓨터)은 0.5초 `임시` → 멈추고 0.5초 뒤 바로 열린다.
  - 알바도 작업 지점(슬롯)에 도착한 뒤 0.5초 `확정` 기다린다 (알바 전용 `StaffRules.interactionDelay`, [11.4](#114-작업-ai-상태-머신-1순위)).
- 게이지 존에서 벗어나면 진행이 **멈추고 유지된다** (구매 패드에 넣은 재화 유지). 다시 올라서면 이어서 진행.
- 운반 존에서 집기와 내려놓기가 둘 다 가능하면 **내려놓기를 우선**한다.

### 5.3 운반 규칙 `1순위`

- 들고 있는 화물은 머리 위로 쌓아서 보여준다. 최대 적재 수에 도달하면 스택 위에 **MAX** 표시.
  - **바뀜** (2026-11-16, M14-4): 맨손은 **손 바로 위**부터 한 줄로 쌓는다. 구루마(`Wagon`) · 롤테이너(`Rolltainer`)는 캐릭터 **앞에 두고 밀며**, 도구 바닥부터 **한 줄로 높게** 쌓는다 (많이 쌓을수록 이동 때 더 기울어짐 — 기존 관성 기울기). 지게차는 M11-8 `확정`. 맨손 상자 바닥 = 캐릭터 기준 높이 0.55m · 앞 0.45m (큰 머리와 겹치지 않게) `임시`
  - 애니: 맨손으로 들고 서 있기 = `carry_idle`, 들고 걷기 = `carry_move`, 구루마 = 서기 `push_wagon_idle` · 걷기 `push_wagon`, 롤테이너 = `push_rolltainer_idle` · `push_rolltainer`, 지게차 알바 = `riding` `확정` (2026-11-18, 옛 `push` 하나를 도구별로 나눔)
- **색이 다른 상자를 섞어서 들 수 있다.** 다만 **상자와 쓰레기는 같이 못 든다** (상자를 든 채로는 쓰레기를 줍지 않음). `확정` (2026-11-15)
- **색 맞춰 내려놓기** `확정` (2026-11-15): 상자는 **같은 색 보관 구역**에만, 찌그러진 상자는 **반품 구역**(반품 선반)에만 넣는다. 다른 곳에 멈추면 넣지 않고 **'넣을 수 없음'** 표시를 띄운다.
- 존은 자기가 받는 화물만 가져간다. 예를 들어 초록 선반 둘레 존에서는 초록 상자만 빠져나가고, 나머지 상자는 아래로 내려앉아 다시 정렬된다.
- 받는 존이 없는 화물은 계속 들고 다닌다 (버리기 기능 없음, 쓰레기만 쓰레기장에 버림).
- **수요 기반 집기**: 선반 둘레 존에서는 현재 처리 중인 주문에 **필요한 품목을 필요한 수량만큼만** 집는다 (과집기 방지). → [8.4](#84-수요-계산)
- **상호작용 쿨타임** (플레이어만): 한 존에서 **내려놓기 ↔ 집기로 바뀔 때 0.5초** `임시` 쉰다. 다 내려놓고 바로 다른 물건을 집어 버리는 일을 줄인다. `확정`
- **작업 고정** (플레이어만): 지금 하는 일의 화물을 들고 있는 동안에는 **그 일만** 할 수 있다. 들고 있는 화물과 출처(트럭 · 하차 칸 / 선반 / 반품 / 쓰레기)가 다른 화물은 다 내려놓기 전까지 집지 않는다. `확정`
  - 예: 하차 칸에서 보관용으로 집은 상자를 들고 선반에 가면, 그 선반 색만 내려놓고 상차용 상자는 집지 않는다.
  - 이유: 들고 있는 화물마다 어디로 갈지 UI로 표시하지 않으므로, 서로 다른 일의 화물이 섞이면 플레이어가 헷갈린다.
- **가이드 화살표** (플레이어만): 들고 있는 화물이 가야 할 곳을 가리킨다 (트럭 상자 → 가장 가까운 하차 칸 공간, 하차 칸 상자 → 그 색 보관 구역 선반, 선반 상자 → 그 색이 필요한 상차 트럭, 찌그러진 상자 → 반품 선반, 쓰레기 → 쓰레기장). **손이 비면 표시하지 않는다.** 목표가 화면 안이면 목표 위에서 아래를 가리키며 통통 튀고, 화면 밖이면 화면 가장자리에서 목표 쪽을 가리키며 늘었다 줄었다 한다. `확정`
- 쿨타임 · 작업 고정 · 화살표는 **알바에게 적용하지 않는다** (알바는 역할대로 움직인다). `확정`

### 7.2 하차 칸 상자 두는 공간 `1순위`

`확정` (2026-11-15, 옛 공용 보관소 팔레트를 대신함 — 이름은 '공용 보관소'를 함께 쓴다)
- 하차 칸마다 하나씩 있는 바닥 공간이다. 트럭 상자는 **반드시 여기를 거쳐** 선반으로 간다. 색을 섞어 쌓는다. 용량 **10** `임시`. 쌓는 모양은 **가로 2 × 세로 2 = 한 층 4개**, 다 차면 위층으로 (10개 = 4 · 4 · 2) `확정` (2026-11-17)
- 하차 알바가 트럭에서 꺼낸 상자를 여기에 쌓고, 플레이어 · **보관 알바**가 여기서 집어 같은 색 보관 구역으로 옮긴다.
- 집을 때는 **그 색 선반에 빈자리가 있는 색만, 빈자리 수만큼** 집는다. 그 색 구역 선반이 가득 차면 그 색 상자는 하차 구역에서 더 옮기지 않는다. `확정`
- 찌그러진 상자도 여기에 쌓인다. 반품 선반이 꽉 차면 찌그러진 상자는 **하차 구역 바닥에 남는다** (→ 7.7).
- 공간 하나를 두른 **둘레 존 하나**로 상호작용한다 (내려놓기 먼저, 없으면 집기).
- **하차 칸마다 따로**다: 하차 칸 N 트럭의 상자는 하차 칸 N 공간에만 둔다. 그 공간이 차면 그 칸 트럭만 막힌다. `확정` (2026-11-15)
- '찼다' = 공간에 있는 수 + 그 칸 트럭에서 꺼내 **손에 든 수**(플레이어 · 알바)가 10. 그러면 플레이어도 알바도 그 트럭에서 더 못 꺼낸다 → 공간이 넘치지 않는다. `확정` (2026-11-15)
- 플레이어가 막히면 그 트럭 위에 **'공간 가득'** 글자를 띄운다 (M13-3 '넣을 수 없음'과 같은 방식). `확정` (2026-11-15)
- 금(6.4)도 이 공간에 쌓이고 **칸을 차지**한다. 플레이어 · 알바 누구든 지나가며 흡수 `확정` (2026-11-18).

```
  → 가운데에서 하나씩 재포장(2초) ─┬→ 쓰레기 1개(항상) → 테이블 옆 출력 쪽(6, 가득 차면 재포장 불가) →(반품 알바 · 플레이어)→ 쓰레기장 (7.9)
                                    └→ 70%: 재포장 상자(같은 색 일반) → 테이블 맞은편 팔레트(6) →(보관 알바 · 플레이어)→ 같은 색 선반 → 상차
```

- **반품 팔레트** (12 `임시`): 보관 알바 · 플레이어가 하차 칸 공간의 찌그러진 상자를 가져다 놓는다. 꽉 차면 찌그러진 상자는 하차 칸 공간에 남는다.
- **재포장 테이블** `확정` (2026-11-17): 길쭉한 테이블. **한쪽 끝 = 입력**(반품 팔레트에서 옮겨 온 찌그러진 상자, 6 `임시`), **가운데 = 재포장 자리**, **반대쪽 끝 = 쓰레기 출력**(6 `임시`), **맞은편 = 재포장 상자 팔레트**(6 `임시`). 모델은 `Return_Inspection_Table` fbx가 없어 임시 큐브.
- **재포장**: 가운데 자리(알바는 슬롯)에 반품 알바 또는 플레이어가 서 있고 입력에 상자가 있으면 **재포장할 상자를 하나씩 바라보며** 재포장한다 (1개당 2초 `임시`, 머리 위 게이지). 끝나면 **쓰레기 1개는 항상** 출력 쪽에, **70%** `임시` 확률로 **같은 색 일반 상자**가 맞은편 팔레트에 쌓인다 (30%는 상자가 없어짐). **쓰레기 출력(6)이나 재포장 팔레트(6)가 가득 차면 재포장을 할 수 없다.**
- **옮기는 사람** `확정` (2026-11-17): 하차 칸 공간 → 반품 팔레트 = 보관 알바 + 플레이어, 반품 팔레트 → 테이블 입력 · 재포장 · 쓰레기 버리기 = **반품 알바** + 플레이어, 재포장 팔레트 → 선반 = 보관 알바 + 플레이어
- 검수 테이블 · 쓰레기 선반 · 재포장 입력 테이블 · '재포장 필요 상자'는 **삭제** (2026-11-17 저녁)

- **반품 구역을 지은 뒤부터** 모든 색 트럭에 **찌그러진 상자**가 일정 확률로 섞여 나온다. 확률은 미정 — 에셋 리스트 예시 **상자 100개당 1개(1%)** 로 둔다 `임시`. 반품 구역이 없으면 섞이지 않는다 (18장 22번 해결).
- 겉모습: **회색 상자 + 원래 색 띠** (모델이 들어오기 전 임시). `확정`
- 찌그러진 상자는 보관 구역 선반에 넣을 수 없고 **반품 팔레트**에만 둔다.
- 재포장 연출: 우당탕탕 먼지. **하다 멈추면** (자리를 떠나면) 진행이 유지되고, **돌아와서 이어서** 한다. `확정`
- **반품 알바**가 재포장 일을 맡는다. **반품 알바가 없으면 플레이어가 직접** 한다 (→ 11.3). `확정`
- 롤테이너 · 스캐너 · 바코드 스캔은 반품에서 삭제. `확정`
- 폐기 분기는 프로토타입 이후로 미룬다.

### 7.10 컨베이어 벨트 `1순위` (Lv.3~)

`확정` (2026-11-23, 기획 요청 — 옛 17장 백로그 '컨베이어 벨트 (자동화)'를 본편으로). 수치는 `임시`.

플레이어가 **직접 설치**하는 바닥 장치. **Start**에서 물건을 받아 일정한 속도로 **End**까지 옮긴다 — 알바가 하던 운반 한 구간을 벨트가 대신한다.

**연결할 수 있는 구간** (Start → End, 물류 순서 '하차 → 공용 보관소 → 선반 → 상차'는 그대로 — 건너뛰는 연결은 없다)

| Start | End | 벨트에 오르는 것 |
|---|---|---|
| 하차 트럭 존 (트럭 뒷문) | **같은 하차 칸**의 상자 두는 공간 (7.2) | 트럭 상자 전부 (일반 · 찌그러진). 금은 오르지 않음 (6.4) |
| 하차 칸 상자 두는 공간 | 보관 구역 선반 (벨트 끝이 닿은 선반 → 같은 구역 4개에 나눠) | **그 구역 색**의 일반 상자, 구역 선반 빈자리만큼 |
| 하차 칸 상자 두는 공간 | 반품 팔레트 | 찌그러진 상자 |
| 보관 구역 선반 (같은 구역 4개에서 꺼냄) | 상차 트럭 존 | 그 구역 색 상자, **정차한 상차 트럭 주문에 남은 수만큼** (8.4 수요 규칙). 트럭이 없거나(1파트 포함) 그 색 주문이 없으면 쉼 |
| 반품 팔레트 | 재포장 테이블 입력 | 찌그러진 상자 |
| 재포장 테이블 쓰레기 출력 | 쓰레기장 쓰레기통 앞 | 쓰레기 |
| 재포장 상자 팔레트 | 같은 색 선반 | 재포장한 일반 상자 |

- **D 가구 큰 상자는 벨트에 오르지 않는다** (지게차 알바만, 5.1). 팔레트 랙도 Start · End가 될 수 없다.
- 표에 없는 조합은 End로 고를 수 없다 (그 존을 눌러도 초록으로 안 바뀜).

**옮기는 규칙**
- 벨트는 **2m 격자** 칸으로 이어진다 (바닥 타일 한 장, 모듈 1칸 = 5 × 5). 한 칸에 상자 **1개**, **초당 1칸** `임시`.
- **올리기 연출** `확정` (2026-11-24, 순간이동 피드백): 더미 · 선반에 **착지한 뒤 0.3초** `임시` 지난 상자만 벨트가 가져간다 (쌓이는 모습이 보이게). 벨트에 올라갈 때는 꺼낸 자리에서 벨트 첫 점까지 **플레이어가 집을 때와 같은 포물선 점프**(같은 시간 · 높이), 착지해야 벨트를 따라 움직인다. 벨트에서 내릴 때는 원래 쌓기 점프 그대로.
- **Start · End는 기능 오브젝트의 가로 · 세로 축에 맞춰 붙는다** `확정` (2026-11-24, 흐름 테스트 피드백 · 같은 날 뜻 바로잡음): 벨트 끝은 오브젝트(트럭 뒷문 · 공간 · 선반 등) **중심을 지나는 가로 또는 세로 축 위**에서 그 오브젝트의 변에 닿는다. 그린 경로의 끝이 축에서 벗어나 있으면 **연결 구간(꺾임)을 자동으로 더해** 축에 맞춘다 → 상자는 축을 따라 일직선으로 오브젝트에 들어가고 나온다. (시험 벨트에서 끝이 오브젝트 축과 어긋나 비스듬히 넘어가는 모습이 어색했음 — "대각선 금지"가 아니라 "주요 오브젝트 축에 최대한 가깝게 이어 붙이기")
  - **예외 — 보관 구역 선반 사이** `확정` (2026-11-24): End가 보관 구역이면 상자는 벨트 끝이 닿은 선반으로 일직선으로 넘어가고, 그 선반이 차 있으면 **같은 구역의 빈자리 있는 다른 선반으로 짧은 포물선 점프**(대각선 허용). Start가 보관 구역이면 반대로 구역 4개 선반 중 재고가 있는 선반에서 벨트 끝으로 점프해 올라온다. 닿은 선반을 먼저 쓴다.
- **여러 벨트** `확정` (2026-11-24): 한 Start에서 여러 벨트, 한 End로 여러 벨트 모두 허용. 같은 Start의 벨트들은 **번갈아** 올린다. 오브젝트 한 변에는 격자 칸이 다르면 벨트 끝을 여럿 붙일 수 있다.
- Start는 벨트 첫 칸이 비면 하나씩 올린다. End는 받는 쪽에 자리가 있으면 내려놓고(자동으로 쌓임), **자리가 없으면 맨 앞 상자부터 멈추고 뒤 상자들이 줄지어 멈춘다**. 자리가 나면 다시 움직인다.
- **벨트 위 물건은 누구도 집을 수 없다** — 상호작용은 Start · End 존에서만.
- '찼다' 계산에 **벨트 위에서 그쪽으로 가는 수도 넣는다** (손에 든 수와 같은 방식, 7.2 · 8.4) → End가 넘치지 않는다. 예: 하차 칸 공간 10 = 공간에 있는 수 + 손에 든 수 + 벨트 위 수.
- 벨트가 연결된 존에서도 **플레이어 · 알바가 그대로 일한다** — 벨트는 일꾼 한 명처럼 같은 트럭 · 공간 · 선반을 나눠 쓴다. 알바는 할 일이 없으면 다른 일을 찾는다 (11.4).
- 벨트는 **바닥 장치**라 플레이어 · 알바가 밟고 지나간다 (길을 막지 않음, 알바 길찾기에 영향 없음).
- 파트 교대(1파트 하차 · 2파트 상차, 9.5)는 벨트에도 같다 — 트럭이 없으면 그 구간 벨트가 자연히 쉰다. **선반 → 상차 벨트는 주문이 있을 때만 올리고 미리 채워 두지 않는다**. 상차 트럭이 회차하면 그 벨트 위 상자는 **꺼낸 구역 선반으로 돌아간다** (7.6 회차 뒤 들고 있던 택배와 같은 규칙) `확정` (2026-11-24)

**설치** — B책상 **`벨트`** 탭 (Lv.3~, 4.3)
1. 탭의 **[설치]** → 팝업이 닫히고 **설치 상태**가 된다. **게임 시간은 멈춘다** (팝업과 같음).
2. 카메라가 **위에서 내려다보는 각도로 꺾이며 줌아웃**하고 부지에 2m 격자가 보인다. 화면 이동 = 드래그(모바일은 두 손가락) · 줌 = 핀치 / 휠.
3. **배치할 수 없는 칸은 붉은색**: 잠긴 칸 · 부지 밖, 시설 자리(선반 · 랙 · 책상 · 테이블 · 저금통 등), **상호작용 존 위**. ~~다른 벨트 위~~ → **다른 벨트와는 겹쳐도 되고, 그리는 벨트 자신과만 겹칠 수 없다**(같은 자리를 오가는 기형 벨트 방지) `확정` (2026-11-24). (Start · End로 고르는 존은 예외 — 벨트 끝이 그 존 가장자리에 닿는다.)
4. **첫 클릭 = Start**: 상호작용 존(하차 트럭 존 · 하차 칸 공간 · 선반 등, 위 표의 Start)을 누른다 → **파란색**. 이후 마우스를 움직이면 마지막 점에서 **가로 또는 세로**(움직인 거리가 큰 쪽)로 **반투명 미리보기 상자**가 칸마다 채워지거나 지워진다. 붉은 칸에서는 더 늘지 않는다.
5. **다음 클릭**: 그 자리에 End가 될 존이 없으면 **꺾임 점**이 되고, 그 점을 기준으로 다시 4처럼 늘린다. End가 될 존이면 **End → 초록색**, 그리기가 끝난다.
6. End가 정해지면 화면 오른쪽 아래 반투명하던 **[저장]** 이 켜진다 → 누르면 확정되고 **칸 수 × 20** `임시`을 지갑에서 낸다 (저금통 돈은 못 씀, 5.1과 같음).
- **모바일**: 누른 채 끌면 미리보기가 늘어나고, **손을 떼면 그 자리가 꺾임 점(또는 End)**. 한 손가락 = 벨트 그리기, 두 손가락 = 화면 이동 · 줌. PC는 위 클릭 · 마우스 이동 그대로.

### 9.5 저금통 · 파트 종료 정산 `1순위`

**돈 흐름** `확정` (2026-11-15)
1. 상차 트럭 출발 → 돈 떨어지는 공간에 지폐 다발 생성 (`금액 += 실린 상자 수 × 색 단가` `임시`)
2. 돈 떨어지는 공간에 쌓인다 (보이는 다발 최대 40개, 넘으면 맨 위 `+금액`). 줍지 않아도 사라지지 않는다.
3. 플레이어가 반경 안에 들어오면 줍기 → **저금통** 금액 증가 (금은 2배, 6.4)
4. 돈을 쓸 때는 **지갑만** 줄어든다 (저금통 돈은 못 씀)
5. 파트 끝 → `지갑 += 저금통 − 알바 월급`, 저금통 = 0 → **정산 팝업**. **할당량 보너스는 삭제** `확정`
   - **바뀜** (2026-11-20): 정산은 **2파트(상차)가 끝날 때만** = **일일 정산**(영수증 출력기 연출, `DAY N`). 1파트(하차)가 끝나면 정산 없이 `파트 교대 / 파트1(하차) → 파트2(상차)` 배너만 띄우고 바로 2파트 `확정`. 정산 중 배경은 어둡게(검정 70%) `임시`
   - 일일 정산의 알바 시급 = **하루 한 파트 몫** (도중 고용은 고용한 파트의 남은 비율) `확정` (2026-11-20)
6. 남은 돈 더미는 다음 파트로 넘어간다

**시간 흐름 (파트타임)** `1순위` `확정`
- 파트 길이 고정 **180초** `임시`. **'첫 파트만 90초'는 삭제** (2026-11-15). 레벨표 시간 계산 기준 = 파트 1번 3분. 일시정지 · 팝업 중에는 멈춘다. 출퇴근 · 출입구 없음.
- HUD에 **파트 남은 시간**을 표시한다.
- **남은 시간 보너스** (2026-11-20) `확정`: 그 파트에 더 할 일이 없으면 남은 시간을 보너스로 바꾼다. 한 번 시작하면 파트 끝까지 (1파트엔 선반이 줄지 않고 2파트엔 재고가 늘지 않아 다시 풀리지 않음). 사무실 전 튜토리얼(시계 없음)엔 없다.
  - 1파트(하차): **선반(랙)부터** — 하차 칸 상자를 그 색 선반에 더 옮길 자리가 없고, **그다음 하차 칸 공간(팔레트)**에도 더 놓을 자리가 없을 때 (정차한 D 트럭이 팔레트 랙에 바로 넣을 수 있으면 아직 할 일 있음)
  - 2파트(상차): 정차한 상차 트럭이 원하는 색이 **선반 · 하차 칸 · 누군가의 손** 어디에도 없고, 새 상차 트럭도 올 수 없을 때 (정차 트럭이 없으면 새 트럭이 못 오는 것만 봄)
  - 남은 시간이 **3초 동안** `임시` 빠르게 0까지 줄고, **10초당 보너스 5** `임시`(10초 안 되는 나머지는 버림 — 180초 = 90)이 줄어드는 만큼 **저금통에 함께 오른다**. 영수증에 `시간 보너스 +N`(그날 1 · 2파트 합) 줄을 따로 둔다. 사무실 전(저금통 없음)엔 바로 지갑에 들어가고 영수증 줄에만 보인다.
  - '할 일 없음'이 **2초** `임시` 이어져야 시작한다 (모듈이 막 켜질 때 · 트럭 교대 같은 잠깐의 빈틈 무시, 2026-11-20 구현 중 추가).

**사무실 투명 저금통** `1순위`
- 이번 파트에 모은 돈을 사무실의 **유리 저금통**으로 보여준다. **지폐**가 **3단계** `임시`로 차오르고 정산 때 비워져 **지갑(UI)으로 이동**한다. `확정` (2026-11-15 결정 5)
  - **꽉 차도 돈은 계속 모이고**, 모습만 더 차오르지 않는다.
  - v1(임시 프리미티브): 사무실 한쪽에 사람 키만 한 **반투명 원통** + 안에 **지폐 층**이 3단계로 높아짐, 위에 금액 글자, 돈이 들어올 때마다 살짝 튐.
- 가득 기준 = `MAX(300, 직전 파트 정산액 × 1.2)` `임시`

**정산 팝업** `1순위`

### 9.6 시작 — 빈 땅에서 건물 세우기 `1순위`

`확정` (2026-11-18, 기획 타임라인 `Document/타임라인.xmind` — 참고 사진: 가설 울타리 · 입구가 있는 공사 부지)
1. 플레이어는 **빈 땅 밖 도로변**, 건물이 될 공간 **입구** 앞에 서 있다. 빈 땅 안에 **지폐 발판** 하나가 있다.
2. 발판으로 걸어가 돈을 넣으면 **플레이어가 선 곳을 기준으로 건물(13칸 부지)이 세워진다** (팝 연출).
3. 건물 안에 발판이 **하나씩 차례로** 나타난다: **하차 구역 → 보관 구역 A(갈색) → 상차 구역**. 하나를 지어야 다음 발판이 나온다.
4. 상차 구역을 지으면 **하차 트럭이 오기 시작**한다 → 상자 내리기 → 보관 구역 → (다음 하차 트럭) → 상차 구역으로 → **상차 트럭이 처음 도착** → 다 싣고 출발. 이때부터 트럭은 계속 온다.
5. 그다음 **사무실 자리에 발판**이 나온다. 물류로 돈을 벌어 사무실을 짓는다. 사무실과 함께 **A책상 · 저금통**이 생긴다 (4.3).
6. 사무실을 지으면 **첫 고용**: **하차 알바 1명**을 무료로 뽑고(13), 알바 1명을 더 **자유 선택**해 가진 돈에 맞게 고용할 수 있다 (Lv.1 최대 알바 2, 10.3).
7. 그 뒤로는 레벨 제도대로 (B보관 초록 건설 타일 → Lv.2 …).

- **돈** `확정`: 시작 지갑 = 처음 네 발판(건물 · 하차 · A보관 · 상차) 합계와 딱 같게 (`임시` 20 · 10 · 10 · 10 = 50). 사무실 발판은 물류로 번 돈으로 (`임시` 100).
- **사무실 전** `확정`: 저금통이 없으므로 **주운 돈은 바로 지갑**으로 들어가고 **파트 시계는 멈춰 있다** (정산 · 월급 없음). 사무실을 지으면 파트 시계 · 저금통 · 정산이 시작된다 (9.5).
- 이 발판들은 건설 타일(9.2)과 같은 방식(서 있으면 지갑 돈이 들어감, 모자라면 이어서)이고 XP는 주지 않는다 `임시`.
- 쓰레기장은 건물과 함께 생긴다 `임시` (반품 구역 전에는 쓰지 않음).
- 레이아웃(도로 · 입구 위치, 발판 자리)은 지금 6 × 4 배치 그대로 `임시` — 하차 1 (4,2) · A보관 (3,3) · 상차 1 (2,4) · 사무실 (2,1).
- **빈 땅** `확정` (2026-11-18): 13칸 자리에 바닥만 있고 둘레에 **공사 울타리**(지금 `ConstructionFence` 재사용), **입구는 사무실 칸 (2,1) 바깥 도로 쪽** 한 곳만 트임. 플레이어는 입구 앞 도로변에서 시작, 첫 발판(건물)은 입구 안쪽.
- **건물 연출** `확정`: 돈을 다 넣으면 울타리가 사라지고, **플레이어가 선 칸부터 거리 순서로** 바닥 · 벽 · 쓰레기장이 차례로 팝 (약 1초).
- **다른 건설 타일** `확정`: 시작 순서(건물 → 하차 1 → A보관 → 상차 1 → 사무실) 동안에는 **그 순서의 발판 하나만** 보인다. **사무실을 지은 뒤부터** B보관 등 레벨 건설 타일이 나타난다.
- **테스트** `확정`: 디버그 메뉴 **[시작 건너뛰기]** — 누르면 시작 발판 5개가 다 지어진 상태(옛 Lv.1 시작과 같음). 빌드에서는 Development Build에서만.
- **구현** (2026-11-18, M16-5): 건물 전에도 13칸에 빈 바닥 타일이 깔려 있다(부지 땅이 낮아 그 위에 서야 함). 건물을 사면 쓰레기장 · 빈 공간 칸은 진짜 모듈로 바뀌며 팝, 하차 · 보관 · 상차 · 사무실 칸은 빈 바닥 그대로 열린다. 사무실 전 트럭은 상차 1을 지어야 오고, 상차 트럭은 상차 1이 생기면 바로 온다(빈 상차 칸이 주문을 만듦). 시작 발판 비용은 `EconomyConfig.startBuildCosts` `임시`.

## 11. 알바생

### 11.1 고용 (클립보드 책상 고용 탭) `1순위`

- 사무실 **클립보드 책상** 메뉴에 `고용 | 배치` **탭**이 있고, 고용 탭에서 고용한다. 메뉴를 열면 고용 탭이 열린다. `확정` (2026-11-15, 옛 계약 PC 팝업을 두 책상으로 나눔 → 4.3)
- 변경사항 2: **돈이 모자라면 고용 버튼(카드)이 회색**, **최대 인원이면 고용 불가**. 고용하면 알바가 **사무실에서 나와 맡은 자리로 간다**. `확정`
- 고용 탭 `확정` (아래 도장 방식은 유지 `임시`)
  - **후보 3명** `임시`을 카드로 보여준다: 외형(코스튬) · 스탯(이동 · 적재, 파생값 m/s · 개수 함께) · 고용금 · 월급. 지갑 돈이 모자란 후보 카드는 회색.
  - 위 왼쪽에 `알바 n/최대 · 지갑`, 위 오른쪽에 **다음 후보 교체까지 남은 시간**(= 파트 남은 시간)과 그 아래 **[새로고침]**(무료) 버튼.
  - 오른쪽 아래 **도장을 끌어 후보 카드에 놓으면** 고용한다. 도장은 평소 앞모습, 들면 윗모습이고, 찍을 때 꾹 누르듯 조금 커졌다 돌아와 카드 위에 잠깐 머문 뒤 제자리로 간다 (연출 값은 `StampConfig` 에셋에서 조절). 고용한 카드에는 붉은 `[ 고용 ]` 도장 자국이 대각선으로 크게 찍히고 불투명한 회색 필터가 덮인다 (다음 교체까지 그대로 남음).
  - 고용할 수 없으면(지갑 돈 부족 / 최대 인원 / 이미 고용함) 도장이 제자리로 돌아가고 카드가 좌우로 흔들리며 사유가 뜬다.
  - 후보는 **파트가 바뀔 때마다** 자동으로, 또는 [새로고침]으로 3명 모두 새로 뽑힌다.
  - 고용해도 팝업은 **열린 채**다 (연달아 고용 가능). 팝업 중에는 게임이 멈추므로 알바 등장 연출은 닫은 뒤에 이어서 보인다.
- 고용금은 **지갑**에서만 낸다. 고용 XP는 없다 ([10.1](#101-경험치-1순위)).
- **외형 랜덤 (코스튬)** `2순위` `확정` (2026-11-15): 대부분은 **물류 유니폼**이고, 일정 확률 `임시`(10%)로 **코스튬 알바**(예: 마카롱 알바생)가 나온다. 하는 일은 같다. 코스튬은 **바꿀 수 없다**. '코스튬 자랑하기' 애니메이션을 연결한다. 모델: **유니폼 = `Model_1.0` uniformT**(걷기 · 들기 애니), **코스튬 = macaron · rabbit** (같은 확률로 하나). 2026-11-19 **macaron2**(마카롱 보라 텍스처) 추가 — 코스튬 3종 같은 확률. `확정` (2026-11-16) — **SBS는 플레이어 아바타 `player_SBS`로 옮김** (2026-11-18, 알바 코스튬에서 빠짐)
- **스탯은 고용할 때 랜덤**으로 정한다 (11.2). 변경사항 2의 스탯 삭제는 취소. `확정` (2026-11-16)
- 고용하면 알바 1명이 **클립보드 책상 앞**에 팝 연출과 함께 나타나 맡은 직무 자리로 걸어간다. **직무는 후보마다 정해져 나온다** `확정` (2026-11-18): 후보 3명 각각 **열린 직무 중 무작위**(같은 확률, 반품은 반품 구역 · 지게차는 D보관을 지은 뒤 열림). 후보 카드에 직무(지게차는 아이콘 `Art/Temp/forklift`)를 보여 준다. 원하는 직무가 없으면 [새로고침]. 고용 뒤 **직무는 바꿀 수 없다** (옛 '뽑은 뒤 자동 배정 + 배치 탭에서 변경' 삭제).
- 알바 외형: 모델 적용됨 (macaron · rabbit 무작위, 2026-11-14) + 발밑 **직무별 색** 원판 (색은 `StaffRules`에서 조정). 직무가 바뀌면 색도 바뀐다. `임시`
- 최대 알바 수는 레벨에 따라 늘어난다 ([10.3](#103-레벨-테이블)). 최대 인원이면 고용할 수 없다.
- **해고** `확정`: **클립보드 책상** 배치 탭에서 언제든 해고할 수 있고, 빈자리는 다시 고용한다. 고용금은 돌려받지 않는다. 해고한 알바는 명단에서 바로 빠지고, 들고 있던 화물을 배달한 뒤 책상 앞으로 걸어가 사라진다.

### 11.2 스탯 `1순위`

`확정` (2026-11-16): 변경사항 2의 **스탯 삭제는 취소**한다. 알바는 계속 **이동 속도 · 적재량** 2가지 스탯을 가진다 (v0.4 규칙 그대로, 이미 구현됨 M6-2). 모든 스탯은 **최소 1**, 최대 5다.

| 스탯 | 효과 | 공식 | 스탯 1 | 스탯 3 | 스탯 5 |
|---|---|---|---|---|---|
| **적재량** | 최대 적재 수 +1 / 1포인트 | `기본 적재 2 + (적재량 − 1)` | 2개 | 4개 | 6개 |
| **이동 속도** | 이동 속도 +20% / 1포인트 | `기본 속도 2.5 m/s × (1 + 0.2 × (이동 속도 − 1))` | 2.5 m/s | 3.5 m/s | 4.5 m/s |

- 기본 적재 2, 기본 속도 2.5 m/s, 집기 간격 0.25초는 `임시` 값이다.
- 알바는 구루마 · 롤테이너를 쓰지 않는다 — 적재는 스탯으로만. `확정` (2026-11-18)

**스탯 생성** `임시`
1. 스탯 총합을 2~8 중에서 뽑는다. 가중치 2:5 · 3:10 · 4:20 · 5:25 · 6:20 · 7:12 · 8:8 `확정`.
2. 두 스탯을 1로 두고 남은 포인트를 무작위로 나눠 준다 (스탯당 최대 5).
3. 고용금 = `스탯 총합 × 15`, 월급(파트마다) = `스탯 총합 × 4` → 좋은 알바일수록 비싸다.

### 11.3 직무 배치 `1순위`

- 직무는 **하차 · 상차 · 보관 · 반품 · 지게차** 5개다 (지게차 2026-11-18 추가). `확정` (2026-11-15 결정 6 — '운반'은 '보관'으로 용어 통일, 옛 역할 하차 · 분류 · 피킹 · 검수 대체)
- **플레이어는 알바를 직접 움직일 수 없다** (직무만 정함). 할 일이 없으면 **자기 자리에서 대기**한다. `확정`
- 클립보드 책상 메뉴의 **배치 탭**(`고용 | 배치`)에서는 **해고만** 한다. **직무 변경은 삭제** `확정` (2026-11-18).
- 배치 탭(화면 이름 `명부`, 2026-11-19 `임시`)은 **직군별 둥근 칸**(하차 · 보관 · 상차 · 반품 · 지게차, 위아래로 스크롤)이고 칸 제목에 인원 수를 보여 준다. 칸 안 알바 줄 = 이름(밀린 시급) · 이동 속도 · 적재 게이지 · 시급 · [해고] (UI 샘플 직원 명부 방식) `확정`. 반품 열은 **반품 구역을 지은 뒤** 열리고, 그 전에는 회색 `(잠김)` · 놓아도 바뀌지 않으며 자동 배정에서도 빠진다. `임시` (2026-11-16) 알바 카드 = 직무 색 · `알바 N`(고용 순 번호, 미지급이면 옆에 붉은 `₩N 밀림`) · 월급.
- 줄의 **[해고]를 누르면 확인 창**([해고] / [취소]). 끌어서 옮기기는 없다 (**바뀜** 2026-11-19: 옛 '카드를 해고 칸에 끌기'). `확정`

| 직무 | 작업 | 열림 | 대상이 없을 때 |
|---|---|---|---|
| **하차** | 하차 트럭 → 하차 칸 상자 두는 공간 (공간이 차면 기다림) | Lv.1 | 하차 칸 트럭 뒷문 옆 |
| **보관** | 하차 칸 공간 → 같은 색 보관 구역 선반. 찌그러진 상자 → 반품 팔레트, 재포장 상자 팔레트 → 같은 색 선반 `확정` (2026-11-17) | Lv.1 | 보관 구역 선반 옆 |
| **상차** | 선반 → 상차 트럭 (상차 수요만큼, 상차 칸 공간 없음 2026-11-16) | Lv.1 | 상차 칸 트럭 뒷문 옆 |
| **반품** | 반품 팔레트 → 재포장 테이블 입력, 재포장, 쓰레기 출력 → 쓰레기장. **막히는 곳부터**: 쓰레기 출력이 가득(재포장 불가)이면 쓰레기부터, 아니면 재포장 → 테이블 입력 채우기 → 쓰레기 순. 적재 **12개**(스탯 무관, 쓰레기 · 상자). 재포장 속도는 플레이어와 같은 2초, 플레이어와 같이 서 있어도 1배 `확정` (2026-11-17 저녁) | Lv.2 (반품 구역) | 재포장 테이블 옆 |
| **지게차** | **D 가구 상자만**: 하차 트럭 → 팔레트 랙 (하차 칸 공간을 거치지 않음), 팔레트 랙 → 상차 트럭. **예외**: 팔레트 랙에 D가 없고 상차 트럭이 D를 요구하는 중에 D 하차 트럭이 와 있으면 **랙을 거치지 않고 바로 상차**. 또 트럭에서 꺼내 든 D를 넣을 랙 빈자리가 없으면 그것도 바로 상차 (2026-11-19 버그 — 4개 중 3개를 랙에 넣고 멈춤). 적재 **4개 고정**, 이동 속도만 스탯. 고용금 +300 `임시` (2026-11-18) | D보관을 지은 뒤 | 팔레트 랙 옆 |

- ~~C 전자제품: 보관 알바는 롤테이너 전까지 C를 옮기지 않음~~ — **삭제** (2026-11-18, 물품 제한 없음). 알바도 모든 색 일반 상자를 나른다.
- **D 가구 상자**: **지게차 알바만** 나른다. 하차 · 보관 · 상차 알바와 플레이어는 D를 집지 않는다 `확정` (2026-11-18, 옛 '플레이어가 지게차를 산 뒤 모든 알바가 지게차를 타고 나름' 삭제).

### 11.4 작업 AI (상태 머신) `1순위`

```
대기 ──(작업 대상 발견 + 예약)──▶ 집으러 이동 ──▶ 집기 ──▶ 운반 ──▶ 내려놓기 ──┐
  ▲                                                                              │
  └──────────────────────────────(완료 / 대상 사라짐)────────────────────────────┘
```

- 작업 대상은 [8.4 수요 계산](#84-수요-계산)과 예약을 기준으로 고른다 (가까운 대상 우선).
- 집으러 가는 중에 대상이 사라지면 예약을 풀고 대기로 돌아간다.
- 알바의 이동 속도, 최대 적재 수, 집기 간격은 스탯으로 정해진다 → [11.2](#112-스탯-1순위)
- **작업 슬롯** `확정`: 작업 구역(존)마다 작업 지점 1~4개를 둔다. 알바는 **출발할 때** 빈 슬롯을 찾아 예약하고, 그 슬롯에서만 집고 내려놓는다. 빈 슬롯이 없으면 그 자리에서 멈춰 기다린다. 플레이어는 슬롯과 무관하게 존 근처 어디서나 작업한다. 슬롯은 화면에 표시하지 않는다.
  - 기본 수: 하차 존 2 · 상차 존 2 · 하차 칸 공간 둘레 4 · 선반 둘레 4 · 재포장 테이블 1 `임시`
- **대기** `확정`: 할 일이 없으면 [11.3](#113-직무-배치-1순위) 표의 대기 위치 (자기 직무 자리)에서 기다린다.

### 11.5 경로 탐색 `1순위`

- 네비메시로 목적지까지 이동한다. **알바끼리는 충돌하지 않고 겹쳐 지나간다** (회피 끄기).
- 플레이어와도 충돌하지 않는다 `확정`. **선반은 장애물이다** — 알바는 선반을 돌아가고, **플레이어도 선반에 막힌다** `확정`. 트럭은 주차 칸이 부지 밖이라 장애물로 두지 않는다.
- 부지 확장·시설 생성 시 네비메시를 런타임에 다시 굽는다.

### 11.6 대화 말풍선 `2순위` `확정`

- 가끔 알바 머리 위에 말풍선(이모지/짧은 대사)을 띄운다. 알바별 쿨타임 30초 `임시`, 화면 전체 동시 최대 2개.
- 대기 상태가 오래되면 "할 일이 없어요" 같은 말풍선으로 병목을 알려주는 용도로도 쓴다.
- 미지급 상태인 알바는 "월급 주세요" 말풍선을 더 자주 띄운다 (쿨타임 15초 `임시`).
- 애니메이션: `미소 짓기` / `당황하기` 등 이모션

### 11.7 파트 정산 · 월급 `1순위`

> 2026-11-15: 이름을 **시급 → 알바 월급**으로 바꾼다 (변경사항 2). 규칙(일한 비율 · 미지급 · 퇴사)은 그대로. 아래 '시급'은 월급으로 읽는다.

**파트** (→ [9.5](#95-저금통--파트-종료-정산-1순위))

- 시간은 **파트** 단위로 흐른다: 180초 고정 `임시` (첫 파트 90초 삭제). 게임 시작부터 1파트가 시작된다.
- 팝업이 열려 게임이 일시정지된 동안에는 시간이 흐르지 않는다. 앱을 꺼둔 동안에도 흐르지 않는다 (오프라인 진행은 이후).
- 파트가 끝나면 **정산 팝업**: 번 돈(저금통) − 알바 월급 = 합계 → 지갑. [확인]을 누르면 다음 파트.
- **파트는 1 · 2가 반복**된다 (번호가 늘지 않음) `확정` (2026-11-19): **1파트 = 하차 파트**(줄의 하차 트럭이 하차장에 들어옴), **2파트 = 상차 파트**(새 상차 트럭만 옴). 하차 트럭 도착 · 줄(최대 3대 · 20초)은 그대로. **상차 파트가 시작되면 줄에 서 있던 하차 트럭과 하차장에 정차한 하차 트럭(덜 내렸어도)이 바로 회차** `확정` (2026-11-20). **2파트가 끝나면 상차장 트럭도 덜 실었어도 바로 떠나고, 실은 만큼의 돈은 현금 더미 없이 저금통에 바로 들어가 그날 정산에 잡힌다** `확정`. 상차 파트 동안 새로 온 하차 트럭은 줄에서 기다렸다가 다음 하차 파트에 들어간다. HUD 시계 `1파트 하차 · 02:46`. 사무실을 짓기 전(파트 0)은 둘 다 들어온다.

**월급 정산** (파트 정산에 포함)

- 파트가 끝날 때 고용 중인 모든 알바의 월급을 정산 금액에서 차감한다. 고용한 파트는 **일한 시간 비율만큼만** 낸다: `시급 × 고용 때 파트 남은 시간 / 파트 길이`, **올림** `확정` (2026-11-11).
- 쓸 수 있는 돈 = 정산 금액 + 지갑. 모자라면 **고용 순서대로** `밀린 시급 + 이번 시급`을 지급하고, 지급하지 못한 알바는 미지급 처리한다 (부분 지급 없음). 앞 알바를 못 줘도 뒤 알바 몫이 되면 준다.

| 상태 | 조건 | 결과 |
|---|---|---|
| 정상 | 시급을 받음 | - |
| **미지급** | 정산 때 시급을 받지 못함 | 밀린 시급(= 이번 시급)을 기록. 머리 위 **빨간 ₩** 아이콘(위아래로 둥실), 배치 탭 카드에 `₩N 밀림` `확정`. "월급 주세요" 말풍선은 말풍선 작업 때. **작업은 계속한다** |
| **퇴사** | 미지급 상태에서 다음 정산 때 `밀린 시급 + 당일 시급`을 받지 못함 | 명단에서 바로 빠진다. 몸통이 **빨갛게 깜빡이며 제자리에서 두 번 점프**(`화내기` 애니메이션 대신, 모델이 나오면 교체) → 현재 운반을 끝내고 사무실 PC 앞으로 걸어 나가 사라진다. 고용금은 환불하지 않는다 `확정` |

- 밀린 시급은 **다음 정산 때 함께 계산**하고, 그때도 부족하면 퇴사한다. 미리 갚는 [밀린 시급 지급] 버튼은 두지 않는다 `확정` (2026-11-11).
- 정산 팝업: `알바 시급 −N`(실제로 낸 금액, 밀린 시급 포함) 줄 + 그 아래 작은 붉은 글자로 `미지급: 알바 3, 알바 5 — 다음 정산 때 못 받으면 떠납니다` / `퇴사: 알바 2`. 합계가 음수면 붉은색. `확정`
- 출퇴근 · 야간 작업은 이후로 미룬다.
