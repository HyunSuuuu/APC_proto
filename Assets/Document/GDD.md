## 1. 게임 개요

### 1.1 한 줄 소개

작은 물류센터의 신입 센터장이 되어 택배를 직접 나르고, 주문을 처리해 번 돈으로 부지를 넓히고 알바생을 고용해 센터를 자동화하는 **캐주얼 물류 경영 아케이드**.

### 1.2 기본 정보

| 항목 | 내용 |
|---|---|
| 장르 | 하이브리드 캐주얼 · 아케이드 경영 (자동 집기/내려놓기 방식) |
| 플랫폼 | 모바일 (Android / iOS) |
| 화면 방향 | **가로 고정** |
| 엔진 | Unity 6000.3 |
| 시점 | 쿼터뷰 고정 각도 3D |
| 아트 톤 | 귀여운 SD 캐주얼 — 2~3등신 캐릭터, 로우폴리 파스텔 톤. 작은 물류센터가 점점 커지는 성장 판타지 |
| 프로토타입 아트 | 임시 박스/프리미티브로 대체 가능. 화물 구분용 **테이프 색상**만은 처음부터 적용 |

### 1.3 프로토타입 목표

- **진행 목표**: Lv.1에서 시작해 **Lv.11 도달**(반품 시스템 해금). 도달 시 "목표 달성" 연출 후 종료 조건 없이 계속 플레이.
- **목표 플레이 시간**: Lv.11 도달까지 약 25~35분 `임시`

### 1.4 검증 질문

프로토타입 플레이 테스트에서 아래 질문에 답할 수 있어야 한다.

| # | 검증 질문 | 확인 방법 |
|---|---|---|
| 1 | 화물을 자동으로 집고 쌓아 나르는 **손맛**이 기분 좋은가? | 집기 간격·스택 연출 조정 전후 비교 |
| 2 | 5단계 흐름(하차 → 분류 → 피킹 → 포장 → 상차)이 **복잡하지 않고** 이해되는가? | 튜토리얼 없이/있이 첫 주문 완료까지 걸린 시간 |
| 3 | 알바를 고용해 **직접 하던 일이 자동화되는 쾌감**이 Lv.11까지 이어지는가? | 레벨별 플레이어 운반 비율 |
| 4 | Lv.4 **복합 주문·포장** 전환이 자연스러운 난이도 상승인가? | Lv.4 전후 주문 처리 시간 |
| 5 | 성장 속도(레벨업·재화)가 너무 빠르거나 느리지 않은가? | 레벨별 도달 시간 로그 |
| 6 | 이력서에서 **스탯과 비용을 비교하는 고민**이 재미있는가? 시급 부담이 적절한가? | 고용한 알바의 스탯 총합 분포, 미지급·퇴사 발생 횟수 |

### 1.5 디자인 필러

1. **손으로 나르는 재미** — 모든 물류는 플레이어가 직접 해볼 수 있고, 자동 집기와 스택 연출이 기분 좋아야 한다.
2. **눈에 보이는 성장** — 부지가 이어 붙고, 선반이 차고, 알바가 늘어나는 변화가 화면에서 바로 보인다.
3. **한 단계씩 늘어나는 흐름** — 처음에는 단순한 흐름에서 시작해 레벨마다 단계(포장, 2번째 회사, 반품)가 하나씩 추가된다.

## 2. 핵심 루프

### 2.1 사이클 (주문 1건 = 수익 1회)

```
[계약]  사무실 PC에서 회사와 계약 → 그 회사 품목의 분류 선반이 열림
   │
   ▼
① 입고    회사 트럭이 입고 베이에 자동 정차
② 하차    트럭 옆 픽업 존에서 화물을 집음 → 공용 보관소에 내려놓음
③ 분류    공용 보관소에서 집음 → 품목별 분류 선반(적재 존)에 넣음
④ 피킹    주문서에 적힌 품목을 선반(수거 존)에서 꺼냄
⑤ 포장    포장대에 주문 물품을 모두 모으고, 포장 존에 서서 게이지 → 포장 상자 1개   ※ Lv.4부터
⑥ 상차    포장 상자를 그 주문의 출고 트럭에 실음 → 트럭 출발
   │
   ▼
[수익]  현금 더미 생성 → 수거 → 재화 + XP
```

- **Lv.1~3**: 포장소가 없다. 단일 품목 주문만 들어오고 ④에서 꺼낸 물건을 출고 트럭에 **바로** 싣는다.
- **Lv.4~**: 포장소가 열리면서 복합 주문이 등장한다. **모든 주문이 ⑤ 포장을 거친다.**
- **Lv.11~**: 입고 화물에 반품 상자가 섞인다 → 검수 → 반품 랙 → 일반 재고처럼 피킹에 사용.

### 2.2 루프 계층

| 계층 | 주기 | 내용 |
|---|---|---|
| 마이크로 | 수 초 | 존에 들어가 자동으로 집기/내려놓기, 패드 게이지 채우기 |
| 메인 | 30초~1분 | 주문 1건 처리 → 현금 수거 |
| 메타 | 2~4분 | 레벨업 → 해금 → 확장·고용·업그레이드 구매 → 처리량 증가 |
| 하루 | 10분 | 하루가 끝나면 알바 시급 정산, 이력서 후보 갱신 → [11.7](#117-하루--시급-정산-1순위) |

## 3. 조작 · 카메라

### 3.1 이동 — 가상 조이스틱 `1순위`

- **플로팅 조이스틱**: UI가 아닌 화면 아무 곳이나 터치하면 그 자리에 조이스틱이 생기고, 드래그한 방향으로 이동한다.
- 손을 떼면 즉시 정지하고 조이스틱이 사라진다.
- 드래그 거리 50% 미만은 걷기, 이상은 뛰기 애니메이션 (속도는 입력 크기에 비례).
- 최대 드래그 반경 80px `임시`

### 3.2 카메라 `1순위`

| 모드 | 동작 |
|---|---|
| **추적 (기본)** | 쿼터뷰 고정 각도(Pitch 45° `임시`, Yaw 45° `확정`)로 플레이어를 부드럽게 따라감 (감쇠 0.15초 `임시`) |
| **자유 이동** | HUD의 **카메라 버튼**으로 진입. 한 손가락 드래그로 맵 이동, 핀치로 확대·축소 |

- 자유 모드에서는 조이스틱이 꺼진다. 카메라 버튼을 다시 누르면 플레이어 위치로 0.4초 동안 부드럽게 복귀한다.
- 줌 범위: 카메라 거리 12~30, 기본 18 `임시`
- **이동 범위 제한** `2순위`: 해금된 부지 경계 밖으로 카메라가 나가지 않는다. 부지를 확장하면 경계도 함께 넓어진다.

## 4. 맵 · 레이아웃

### 4.1 원칙

- 물류센터 **양옆에 주차장이 하나씩** 있다: 왼쪽 **하차(입고) 주차장**, 오른쪽 **상차(출고) 주차장**. `확정`
- 물류센터 안에서는 물류가 **왼쪽(하차) → 오른쪽(상차)** 으로 흐른다.
- 트럭은 주차장 바깥쪽에 나타나 자기 주차 칸으로 **후진으로 곧장 들어온다** — 앞머리는 바깥쪽, 뒷문은 물류센터 쪽. 도로 주행 연출은 없다. 트럭은 주차장 안에만 있으므로 물류센터 안의 플레이어 · 알바와 마주치지 않는다.
- 하차 · 상차 존은 트럭 뒷문 앞(주차장 모듈 안, 물류센터 쪽 끝)에 있다.
- 부지는 **모듈**(n × m 칸 프리팹)을 config(`SiteLayout`)에 적힌 위치 · 해금 조건대로 붙여 만든다 (→ TechStack 5.7). 확장 = 잠긴 칸에 모듈을 붙이는 것.
- **잠긴 칸은 보이지 않고 들어갈 수도 없다.** 플레이어 · 알바는 열린 칸 안에서만 움직인다 (가장자리에서는 벽을 따라 미끄러짐). 해금하면 모듈이 팝 연출과 함께 **뿅 나타나고** 바로 걸어 들어갈 수 있다. `확정`
- 부지 바깥 바닥(초록 Ground)은 임시이며 나중에 지운다.
- 베이는 진입로를 따라 **아래로(세로) 늘어난다**. 베이 확장은 주차장 열의 아래 칸을 여는 것이다.
- 확장 칸은 이미 열린 칸과 붙어 있어야만 해금할 수 있다 (섬처럼 떨어진 칸 없음).

### 4.2 부지 그리드 `임시`

- 칸 한 변 **10m** (칸 사이 이동 약 2.5초). 카메라는 쿼터뷰(Yaw 45°)라 부지는 화면에서 **마름모(아이소메트릭)** 로 보인다. `확정` (Yaw 0° 정면 배치는 시험해 본 뒤 제외)

```
 도로 ══╦══════════════════════════════════════════════════════════════╦══▶
        ║ 진입로                                                 진입로 ║
       C0 하차 주차장   C1              C2              C3              C4 상차 주차장
  R1   ■ 하차 베이 1   ■ 공용 보관소   ■ 선반 구역 A   ■ 출고 구역     ■ 상차 베이 1
         🚚→ [하차 존]   내려놓기·집기   선반 4개        (통로)          [상차 존][현금] ←🚚
  R2   🔒 E1           ■ 사무실        🔒 E2           🔒 E3           🔒 E5
       하차 베이 2·3     계약 PC         선반 구역 B     포장 구역       상차 베이 2·3
                         고용 데스크
                         배치 현황판
                         업그레이드 패드
  R3                   🔒 E6           🔒 E4
                         반품 구역       선반 구역 C

  ■ = 시작 부지   🔒 = 잠긴 확장 칸   🚚→ = 트럭 뒷문 방향
```

| 칸 | 내용 | 해금 레벨 | 확장 비용 `임시` |
|---|---|---|---|
| 시작 부지 | 하차 주차장(베이 1), 공용 보관소, 선반 구역 A, 출고 구역, 상차 주차장(베이 1), 사무실 | Lv.1 | - |
| E1 | 하차 베이 2 (Lv.10에 베이 3 구매 패드) — 하차 주차장 아래 칸 | Lv.2 | 100 |
| E5 | 상차 베이 2 (Lv.8에 베이 3 구매 패드) — 상차 주차장 아래 칸 | Lv.3 | 150 |
| E3 | 포장 구역 (포장대 1, Lv.8에 포장대 2 구매 패드) | Lv.4 | 250 |
| E2 | 선반 구역 B (B사 선반 + 추가 선반 자리) | Lv.6 | 350 |
| E4 | 선반 구역 C (추가 선반 자리) | Lv.9 | 500 |
| E6 | 반품 구역 (검수 테이블, 반품 랙) | Lv.11 | 600 |

- 칸 하나는 바닥 타일 + 내벽/외벽 모듈 묶음이다. 해금하면 바닥과 벽이 이어 붙는 팝 연출이 나오고, 인접 칸 사이의 벽은 제거된다.

### 4.3 사무실 `확정`

- 계약 PC, 고용 데스크, 배치 현황판이 모여 있는 곳이다.
- **순간이동은 없다** — 플레이어가 걸어서 가야 한다.
- 사무실이 화면 밖에 있으면 화면 가장자리에 방향 화살표가 뜬다 (→ [12.1](#121-hud-1순위)).

## 5. 플레이어

### 5.1 기본 수치 `임시`

| 항목 | 기본값 | 업그레이드 (2순위) |
|---|---|---|
| 이동 속도 | 4.0 m/s | 4.5 → 5.0 → 5.5 |
| 최대 적재 수 | 5개 | 7 → 9 → 12 |
| 집기/내려놓기 간격 | 0.15초 / 1개 | - |

### 5.2 상호작용 존 `1순위`

존은 두 종류다. 모든 존은 바닥 마킹으로 표시한다.

| 종류 | 동작 | 해당 존 |
|---|---|---|
| **운반 존** | 존 안에 있는 동안 간격마다 1개씩 자동으로 집거나 내려놓음 | 트럭 픽업 존, 공용 보관소, 선반 적재 존 / 수거 존, 포장대, 포장 완료 존, 출고 트럭 상차 존, 검수 테이블, 반품 랙 |
| **게이지 존** | 존 위에 서 있으면 게이지가 차고, 다 차면 동작 실행 | 구매/해금 패드, 업그레이드 패드, 계약 PC, 고용 데스크, 배치 현황판, 포장 존, 검수 |

- **상호작용은 존 안에서 멈춰 있을 때만 일어난다.** 움직이면 즉시 멈춘다. 지나가다 실수로 구매·하차하는 일을 막는다. `확정`
  - **운반 존**: 멈춘 뒤 0.5초 `임시`가 지나면 첫 상자를 바로 옮기고, 이후 간격마다 1개씩. 대기 중에는 존 바닥 색이 점점 밝아진다.
  - **게이지 존**: 따로 기다리지 않고 **멈추는 순간부터 게이지가 찬다** (게이지가 곧 대기 시간). 사무실 시설(계약 PC · 고용 데스크 · 배치 현황판)은 0.5초 `임시` → 멈추고 0.5초 뒤 바로 열린다.
  - 알바에게도 같은 대기를 적용할지는 알바 구현(M6) 때 정한다.
- 게이지 존에서 벗어나면 진행이 **멈추고 유지된다** (구매 패드에 넣은 재화, 포장 진행도 모두 유지). 다시 올라서면 이어서 진행.
- 운반 존에서 집기와 내려놓기가 둘 다 가능하면 **내려놓기를 우선**한다.

### 5.3 운반 규칙 `1순위`

- 들고 있는 화물은 머리 위로 쌓아서 보여준다. 최대 적재 수에 도달하면 스택 위에 **MAX** 표시.
- **품목이 다른 화물을 섞어서 들 수 있다.**
- 존은 자기가 받는 화물만 가져간다. 예를 들어 빨강 선반의 적재 존에서는 빨강 상자만 빠져나가고, 나머지 상자는 아래로 내려앉아 다시 정렬된다.
- 받는 존이 없는 화물은 계속 들고 다닌다 (버리기 기능 없음).
- **수요 기반 집기**: 선반 수거 존과 반품 랙에서는 현재 처리 중인 주문에 **필요한 품목을 필요한 수량만큼만** 집는다 (과집기 방지). → [8.4](#84-수요-계산)

## 6. 화물 · 계약

### 6.1 화물 데이터 `1순위`

| 필드 | 내용 |
|---|---|
| 품목 ID | 품목 종류. **테이프 색상**으로 구분 |
| 소속 회사 | 회사 A / 회사 B |
| 상태 | 일반 / 반품 (Lv.11~) / 포장 완료 |
| 크기 | 모두 동일 (포장 상자도 운반 슬롯 1칸) |

### 6.2 회사 · 품목 `임시`

| 회사 | 계약 시점 | 품목 수 | 품목 (테이프 색) | 입고 트럭 적재량 | 품목 단가 |
|---|---|---|---|---|---|
| 회사 A | Lv.1 (튜토리얼) | 2종 | A1 빨강, A2 파랑 | 8개 | 10 |
| 회사 B | Lv.7 | 3종 | B1 노랑, B2 초록, B3 보라 | 10개 | 14 |

- 회사 이름은 미정 (임시: 회사 A / 회사 B). 테이프 색은 색약 사용자를 위해 상자 옆면에 품목 아이콘도 함께 표시하는 것을 권장.

### 6.3 계약 `1순위`

- 사무실 **계약 PC**(게이지 존)에 서면 계약 팝업이 열린다.
- 팝업 내용: 회사 이름, 취급 품목(색 아이콘), 입고 물량, [계약] 버튼. 아직 계약할 수 없는 회사는 "Lv.7 해금" 같은 잠금 표시.
- 계약하면:
  1. 그 회사 품목의 **분류 선반**이 팝 연출과 함께 생성된다.
  2. 그 회사의 입고 트럭이 오기 시작한다.
  3. 그 회사 품목으로 된 주문이 생성되기 시작한다.
- 계약 비용은 없다 (레벨로만 제한).

## 7. 물류 흐름 상세

### 7.1 입고 — 트럭 도착 · 정차 `1순위`

- 입고 트럭은 도로를 따라 들어와 **빈 입고 베이**에 정차한다. 동시 정차 수 = 입고 베이 수 (시작 1).
- 입고 베이는 **하차 주차장**(물류센터 왼쪽)의 주차 칸이다. 트럭은 주차 칸 바깥쪽에 나타나 **후진으로 곧장 주차**하고(앞머리는 바깥쪽, 뒷문은 물류센터), 다 비면 앞으로 나가 사라진다. 도로 주행 연출은 없다 — 베이(주차장 모듈)가 어디에 붙든 혼자 동작하게 하기 위해서다. 하차 존은 트럭 뒷문 앞에 있다. `확정`
- 출고 트럭도 같은 방식으로 **상차 주차장**(물류센터 오른쪽)을 쓴다.
- 트럭 회사는 계약한 회사 중에서 고른다 (가중치 → [7.8](#78-교착-방지-규칙)).
- 트럭 옆 **픽업 존**에서 플레이어나 하차 알바가 화물을 하나씩 꺼낸다. 화물이 다 빠지면 트럭이 출발하고, 4초 `임시` 뒤 다음 트럭이 들어온다.
- 트럭에 남은 수량은 트럭 위 숫자로 표시한다.
- 시작 시 트럭에서 상자를 꺼내는 애니메이션: `트럭에서 상자 내리기`.
- **차량 대기열** `2순위`: 베이가 모두 차 있으면 다음 트럭이 도로에서 대기하고, 대기 차량 수를 표시한다.

### 7.2 하차 → 공용 보관소 `1순위`

- 트럭에서 꺼낸 화물은 **공용 보관소에만** 내려놓을 수 있다 (트럭에서 선반으로 바로 넣기 불가 — [18번 확인 필요](#18-확인-필요-사항)).
- 공용 보관소는 품목을 섞어서 보관하는 바닥 팔레트 구역이다. 용량 20개 `임시` (Lv.6 업그레이드로 30 → 40).
- 공용 보관소는 존이 둘로 나뉜다: **내려놓기 존 (트럭 쪽, 왼쪽)** / 팔레트 / **집기 존 (선반 쪽, 오른쪽)**. 내려놓기 존에서는 놓기만, 집기 존에서는 집기만 한다. `확정`
- 집기 존에서는 **넣을 선반에 빈자리가 있는 품목만, 빈자리 수만큼** 집는다 (이미 들고 있는 같은 품목 수는 뺀다). 쓸모없는 화물을 들고 다니지 않게 한다. `확정`
- 공용 보관소가 가득 차면 트럭 픽업이 사실상 멈추고, 트럭은 화물이 남아 있는 한 베이를 비우지 않는다.

### 7.3 분류 → 분류 선반 `1순위`

- 선반 1개는 **품목 1종 전용**이다. 선반 위에 품목 색 아이콘을 표시한다.
- 선반은 양쪽에 존이 따로 있다.
  - **적재 존**(앞): 그 품목을 넣는 곳 (+1)
  - **수거 존**(뒤): 그 품목을 꺼내는 곳 (−1)
- 공용 보관소에서 집은 화물만 선반 적재 존에 넣을 수 있다.
- 용량: 기본 10 → 선반 용량 업그레이드로 +5씩 최대 35 `2순위`
- 적재량 외형: 선반 칸에 **실제 상자가 하나씩 올라간다** (칸이 차는 모습 = 빈/절반/가득). `확정`
- 선반 위 수량 표시 (예: `7/10`)
- 시작 선반: 회사 A 계약 시 **4개** (A1 × 2, A2 × 2)

### 7.4 피킹 `1순위`

- 플레이어나 피킹 알바가 선반 **수거 존**에서 주문에 필요한 품목을 꺼낸다 (수요 기반 → [8.4](#84-수요-계산)).
- **Lv.1~3**: 꺼낸 물건을 출고 트럭 상차 존에 바로 싣는다.
- **Lv.4~**: 꺼낸 물건을 포장대에 넣는다.

### 7.5 포장 `1순위` (Lv.4 해금)

- 포장대는 한 번에 주문 1건을 처리한다. 대상은 **출고 베이에 정차한 트럭의 주문 중 가장 오래된, 아직 포장 안 된 주문**이다.
- 포장대 위에 현재 작업 중인 주문 카드(품목 아이콘 × 수량, 진행도)를 띄운다.
- **포장대 존**에 들어가면 그 주문에 필요한 물건만 내려놓아진다.
- 필요한 물건이 모두 모이면 **포장 존**에 서 있는 동안 게이지가 찬다 (3초 `임시`). 다 차면 **포장 상자 1개**가 포장 완료 존에 나온다.
- 포장 상자는 어느 주문의 것인지 정보를 가지고 있다 (상자 위 주문 번호/색 태그).
- 재포장(반품)은 검수에 포함된다 → [7.7](#77-반품-1순위-lv11-해금).

### 7.6 상차 → 출고 · 현금 `1순위`

- 출고 트럭은 **주문 1건당 1대**다. 출고 베이가 비면 가장 오래된 미배정 주문의 트럭이 들어온다 → [8.3](#83-주문--트럭-배정).
- 트럭 위에 주문 카드를 띄운다.
- 트럭 상차 존은 **자기 주문에 해당하는 것만** 받는다.
  - Lv.1~3: 주문 품목 원물을 수량만큼
  - Lv.4~: 자기 주문의 포장 상자 1개
- 주문이 충족되면 트럭이 출발한다. 동시에 그 베이의 **현금 존**에 현금 더미가 쌓인다.
- 현금 존은 **베이마다 상차 존 바로 옆**(상차 주차장 모듈 안)에 있다. 상차한 자리에서 바로 보상을 보여주고, 베이를 늘려도 모듈 하나로 끝난다. `확정`
- 출고 구역(C3, 선반과 상차 주차장 사이)은 지금은 **통로**로 비워 두고, Lv.4 포장이 들어오면 포장 완료 존 같은 시설 자리로 쓴다. `확정`
- 플레이어가 현금 존 반경 2m `임시` 안에 들어오면 현금이 플레이어에게 빨려 들어오며 재화가 오른다. **멈출 필요 없이 지나가기만 해도 흡수한다** (받는 행동이라 실수해도 손해가 없으므로 "멈춰야 상호작용" 규칙의 예외). `확정`
- 현금 더미는 **10원당 1뭉치**로 쌓는다. 나머지 금액은 마지막 뭉치에 포함한다 (예: 30원 = 3뭉치, 52원 = 6뭉치). `확정`
- 애니메이션: `트럭에 상자 싣기`

### 7.7 반품 `1순위` (Lv.11 해금)

```
입고 트럭(반품 섞임) → 공용 보관소 → 검수 테이블(검수 = 재포장 포함) → 반품 랙 → 피킹에 일반 재고로 사용
```

- Lv.11부터 입고 화물의 15% `임시`가 **반품 상자**로 들어온다. 반품 상자는 외형이 다르고(반품 스티커), 원래 품목 정보는 그대로 가지고 있다.
- 반품 상자는 분류 선반에 넣을 수 없다. 분류 알바도 반품 상자는 건너뛴다. → 반품을 처리하지 않으면 공용 보관소가 막히는 압박이 생긴다.
- **검수 테이블**: 플레이어가 존에 서 있으면 반품 상자를 하나씩 내려놓고, 상자 1개당 게이지 1.5초 `임시`가 찬다. 다 차면 그 상자는 일반 상태로 바뀌어 옆 **반품 랙**에 자동으로 올라간다.
- **반품 랙**: 품목 구분 없이 10개 `임시` 보관. 수거 존에서 주문에 필요한 품목을 꺼낼 수 있다 (분류 선반과 같은 재고 취급). 랙이 가득 차면 검수가 멈춘다.
- 애니메이션: `물품 검수하기` / `바코드 스캔하기`
- 프로토타입에서 검수는 **플레이어 전용**이다 (반품 담당 알바 역할 없음 — [18번 확인 필요](#18-확인-필요-사항)).

### 7.8 교착 방지 규칙 `1순위`

특정 품목이 선반·공용 보관소에 가득 쌓였는데 주문은 다른 품목만 요구하면 흐름 전체가 멈출 수 있다. 이를 막기 위해 다음 규칙을 둔다.

| 규칙 | 내용 |
|---|---|
| 입고 구성 가중치 | 입고 트럭에 실을 품목은 `(대기 주문의 수요 − 현재 재고)`가 클수록 확률이 높다. 품목마다 최소 가중치 10%를 보장한다. |
| 주문 생성 가중치 | 재고(선반 + 공용 보관소)가 많은 품목일수록 주문에 나올 확률이 높다. |
| 트럭 회사 선택 | 입고 트럭 회사도 위 품목 가중치의 합으로 고른다. |

## 8. 주문 시스템

### 8.1 주문서 `1순위`

- 주문서 내용: **품목별 수량** (예: 빨강 × 3, 파랑 × 2). 제한 시간 없음.
- 주문은 한 회사의 품목으로만 구성한다 (회사 섞임 없음 — [18번 확인 필요](#18-확인-필요-사항)).

| 구간 | 주문 종류 | 구성 `임시` |
|---|---|---|
| Lv.1~3 | 단일 주문만 | 품목 1종 × 2~4개 |
| Lv.4~6 | 단일 40% / 복합 60% | 복합: 품목 2종 × 각 1~3개 |
| Lv.7~ | B사 주문 추가 | 복합: 품목 2~3종 × 각 1~3개 (최대 합계 8개) |

### 8.2 주문 생성 · 큐

- 주문은 일정 간격으로 생성되어 큐에 쌓인다: Lv.1~3 15초, Lv.4~ 12초 `임시`.
- **계약하는 순간 첫 주문 1건이 바로 생긴다** (목표가 처음부터 보이도록). 이후는 위 간격대로. `확정`
- 큐에 쌓인 주문이 8건 `임시`이면 생성을 멈춘다 (무한 누적 방지).
- 큐는 화면 상단에 표시한다 → [12.2](#122-주문서-큐-1순위).

### 8.3 주문 — 트럭 배정

- 출고 베이가 비면 **가장 오래된 미배정 주문**의 출고 트럭이 들어와 정차한다 (진입 3초 `임시`).
- 동시에 처리할 수 있는 주문 수 = 출고 베이 수 (시작 1).
- 플레이어가 처리할 주문을 고르지 않는다 (자동 배정).

### 8.4 수요 계산

`현재 수요` = 정차 중인 트럭 주문의 남은 수량 − 플레이어/알바가 이미 들고 있거나 예약한 수량

- 선반 수거 존과 반품 랙의 수요 기반 집기, 피킹 알바의 작업 대상 선택, 교착 방지 가중치가 모두 이 값을 사용한다.
- 알바가 작업을 고르면 해당 수량을 **예약**해서 여러 알바가 같은 수요를 중복으로 가져가지 않게 한다.

### 8.5 주문 보상 `임시`

| 항목 | 단일 주문 | 복합 주문 |
|---|---|---|
| 재화 | Σ(품목 단가 × 수량) | Σ(품목 단가 × 수량) × 1.3 |
| XP | +10 | +20 |

예) 단일 A1 × 3 = 30 / 복합 A1 × 2 + A2 × 2 = 40 × 1.3 = 52

- Lv.4 전환 규칙: 포장소 해금 **이전**에 이미 트럭이 배정된 주문은 포장 없이 원물로 완료할 수 있다. 해금 이후 배정되는 주문부터 포장이 필요하다.

## 9. 경제 · 건설

### 9.1 재화 `1순위`

- 재화는 **현금 1종**이다 (유료 재화는 백로그).
- 획득 경로: 주문 완료 → 현금 더미 수거 (→ [7.6](#76-상차--출고--현금-1순위))
- 사용처: 확장 칸, 시설 구매, 알바 고용금, 알바 시급(하루 정산), 이력서 새로고침, 업그레이드

### 9.2 구매 / 해금 패드 `1순위`

- 패드에 **아이콘 + 비용**과 게이지 링을 표시한다.
- 패드 위에 서 있으면 보유 재화가 조금씩 들어가고 게이지가 찬다. 모두 들어가는 데 1.5초 `임시` (금액이 커도 시간은 같음).
- 재화가 부족하면 가진 만큼만 들어가고 게이지가 멈춘다. 들어간 금액은 유지된다.
- 게이지가 다 차면 시설이 **팝 연출**과 함께 생성되고 패드는 사라진다.
- 패드는 해금 레벨에 도달해야 나타난다. 다음 레벨에 열릴 패드는 반투명 잠금 상태(`Lv.N`)로 미리 보여준다.
- **업그레이드 패드** `2순위`: 구매 패드와 **색으로 구분**한다 (구매 = 초록, 업그레이드 = 파랑 `임시`). 단계가 오르면 비용이 갱신된 채 그 자리에 남는다.

### 9.3 부지 확장 `1순위`

- 잠긴 확장 칸 위에 해금 패드가 있다. 해금하면 바닥·벽 모듈이 이어 붙으며 부지가 넓어진다.
- 열린 칸과 붙어 있는 칸만 해금할 수 있다 (섬 금지).
- 해금하면 네비메시와 카메라 경계를 갱신한다.

## 11. 알바생

### 11.1 고용 · 이력서 `1순위`

- 사무실 **고용 데스크**(게이지 존, 1초 `임시`)에 서면 **이력서 UI**가 열린다.
- 이력서 UI에는 **후보 3명**이 나온다. 후보 카드에 표시하는 정보:

| 항목 | 내용 |
|---|---|
| 이름 · 초상 | 랜덤 이름, SD 초상 (기본 작업복 색 랜덤) |
| 스탯 | 힘 / 민첩 / 지능 수치 + 효과 미리보기 (예: `힘 3 · 적재 +2`) |
| 고용금 | 고용할 때 한 번 내는 비용 |
| 시급 | 하루 정산 때마다 나가는 비용 (명칭은 시급, 실제로는 하루 1회 지급 → [11.7](#117-하루--시급-정산-1순위)) |
| [고용] 버튼 | 재화 부족 또는 최대 인원이면 비활성 |

- **자동 갱신**: 10분마다(= 하루 시작 시점) 후보 3명이 모두 새로 바뀐다. UI 하단에 다음 갱신까지 남은 시간을 표시한다.
- **유료 새로고침**: [새로고침] 버튼으로 재화를 내고 후보 3명을 즉시 바꾼다. 비용은 `20 × 현재 레벨` `임시`. 자동 갱신 타이머는 그대로 유지된다.
- 고용한 후보 자리는 **다음 갱신까지 빈칸**으로 남는다 ("다음 갱신 때 새 후보").
- 고용하면 고용금이 빠지고, 알바 1명이 사무실 문 앞에 팝 연출과 함께 나타난다. 이어서 **배치 현황판 UI가 자동으로 열려** 역할을 정한다.
- 최대 알바 수는 레벨로 정해진다 ([10.3](#103-레벨-테이블-임시)). 최대 인원이면 데스크에 `MAX` 표시 (이력서 열람은 가능).

### 11.2 스탯 `1순위`

알바는 **힘 · 민첩 · 지능** 3가지 스탯을 가진다. 모든 스탯은 **최소 1**이며, 스탯 1이 기본값이다.

| 스탯 | 효과 | 공식 | 스탯 1 | 스탯 3 | 스탯 5 |
|---|---|---|---|---|---|
| **힘** | 최대 적재 수 +1 / 1포인트 | `기본 적재 2 + (힘 − 1)` | 2개 | 4개 | 6개 |
| **민첩** | 이동 속도 +20% / 1포인트 | `기본 속도 2.5 m/s × (1 + 0.2 × (민첩 − 1))` | 2.5 m/s | 3.5 m/s | 4.5 m/s |
| **지능** | 작업 속도 +20% / 1포인트 | `작업 속도 배율 = 1 + 0.2 × (지능 − 1)` | ×1.0 | ×1.4 | ×1.8 |

- 기본 적재 2, 기본 속도 2.5 m/s는 `임시` 값이다. 스탯 5 알바가 플레이어 기본치(적재 5, 속도 4.0)를 약간 넘는 수준으로 맞췄다.
- **작업 속도**가 적용되는 곳: 집기/내려놓기 간격(기본 0.25초 ÷ 배율), 포장 게이지(기본 4초 ÷ 배율). 검수는 플레이어 전용이므로 해당 없음.
- 역할별로 중요한 스탯이 다르다 — 운반 역할(하차·분류·피킹·상차)은 힘·민첩, 포장은 지능. 이력서와 배치 현황판에서 이를 보고 판단한다.

**후보 스탯 생성** `임시`

1. 스탯 총합을 4~9 중에서 뽑는다: 4 (10%) · 5 (20%) · 6 (25%) · 7 (20%) · 8 (15%) · 9 (10%)
2. 세 스탯을 모두 1로 두고, 남은 `총합 − 3` 포인트를 무작위 스탯에 1씩 나눠 준다 (스탯당 최대 5).
3. 고용금 = `스탯 총합 × 15`, 시급 = `스탯 총합 × 8` → 좋은 알바일수록 비싸다.

### 11.3 역할 배치 `1순위`

- 역할은 5개이며 작업 단계와 1:1로 대응한다.
- 사무실 **배치 현황판**(게이지 존)에 서면 배치 UI가 열리고, 언제든 역할을 바꿀 수 있다.
- 배치 UI의 알바 목록에는 이름, 현재 역할, **스탯, 시급, 미지급 상태**를 함께 보여준다.
- 역할을 바꾸면 들고 있던 화물은 원래 목적지에 배달을 끝낸 뒤 새 역할로 전환한다.

| 역할 | 작업 | 해금 | 대상이 없을 때 |
|---|---|---|---|
| **하차** | 입고 트럭 픽업 존 → 공용 보관소 | Lv.1 | 입고 구역 대기 위치 |
| **분류** | 공용 보관소(일반 상자만) → 빈자리가 있는 해당 품목 선반 적재 존 | Lv.1 | 공용 보관소 옆 대기 |
| **피킹** | 선반/반품 랙 수거 존 → (Lv.1~3) 출고 트럭 / (Lv.4~) 포장대 | Lv.1 | 선반 구역 대기 |
| **포장** | 포장대 포장 존에 상주하며 포장 게이지 진행 (기본 4초 ÷ 지능 작업 속도 배율) | Lv.4 | 포장 존에서 대기 |
| **상차** | 포장 완료 존 → 해당 주문 출고 트럭 | Lv.4 | 출고 구역 대기 |

### 11.4 작업 AI (상태 머신) `1순위`

```
대기 ──(작업 대상 발견 + 예약)──▶ 집으러 이동 ──▶ 집기 ──▶ 운반 ──▶ 내려놓기 ──┐
  ▲                                                                              │
  └──────────────────────────────(완료 / 대상 사라짐)────────────────────────────┘
```

- 작업 대상은 [8.4 수요 계산](#84-수요-계산)과 예약을 기준으로 고른다 (가까운 대상 우선).
- 집으러 가는 중에 대상이 사라지면 예약을 풀고 대기로 돌아간다.
- 알바의 이동 속도, 최대 적재 수, 집기 간격은 스탯으로 정해진다 → [11.2](#112-스탯-1순위)

### 11.5 경로 탐색 `1순위`

- 네비메시로 목적지까지 이동한다. **알바끼리는 충돌하지 않고 겹쳐 지나간다** (회피 끄기).
- 플레이어와도 충돌하지 않는다 `임시`.
- 부지 확장·시설 생성 시 네비메시를 런타임에 다시 굽는다.

### 11.6 대화 말풍선 `2순위` `확정`

- 가끔 알바 머리 위에 말풍선(이모지/짧은 대사)을 띄운다. 알바별 쿨타임 30초 `임시`, 화면 전체 동시 최대 2개.
- 대기 상태가 오래되면 "할 일이 없어요" 같은 말풍선으로 병목을 알려주는 용도로도 쓴다.
- 미지급 상태인 알바는 "월급 주세요" 말풍선을 더 자주 띄운다 (쿨타임 15초 `임시`).
- 애니메이션: `미소 짓기` / `당황하기` 등 이모션

### 11.7 하루 · 시급 정산 `1순위`

**하루**

- 게임 내 **하루 = 실시간 10분** `임시`. 게임 시작(회사 A 계약 완료)부터 1일차가 시작된다.
- HUD에 일차와 하루 진행 시계를 표시한다 → [12.1](#121-hud-1순위).
- 팝업이 열려 게임이 일시정지된 동안에는 시간이 흐르지 않는다. 앱을 꺼둔 동안에도 흐르지 않는다 (오프라인 진행은 백로그).
- 하루가 끝나면 ① 시급 정산 → ② 정산 결과 팝업 → ③ 이력서 후보 자동 갱신 순서로 처리하고 다음 날이 시작된다.

**시급 정산**

- 하루가 끝날 때 고용 중인 모든 알바에게 시급을 지급한다. 고용 첫날은 **일한 시간 비율만큼만** 지급한다 (예: 하루의 30%가 남았을 때 고용 → 시급의 30%).
- 재화가 모자라면 **고용 순서대로** 지급하고, 지급하지 못한 알바부터 미지급 처리한다 (부분 지급 없음).

| 상태 | 조건 | 결과 |
|---|---|---|
| 정상 | 시급을 받음 | - |
| **미지급** | 정산 때 시급을 받지 못함 | 밀린 시급을 기록. 머리 위 💸 아이콘, "월급 주세요" 말풍선. **작업은 계속한다** |
| **퇴사** | 미지급 상태에서 다음 정산 때 `밀린 시급 + 당일 시급`을 받지 못함 | 현재 운반을 끝내고 `화내기` 애니메이션 후 사무실 문으로 걸어 나가 사라진다. 고용금은 환불하지 않는다 |

- 다음 정산 전에 배치 현황판 UI에서 **[밀린 시급 지급]** 버튼으로 미리 해소할 수 있다.
- 정산 결과 팝업: 일차, 총 지급액, 미지급 알바 수(이름), 퇴사 알바(이름). 미지급 알바가 있으면 "다음 정산 때 못 받으면 떠납니다" 경고를 띄운다.
- 시간 흐름의 나머지 기능(파트 구분, 출퇴근, 야간 작업)과 수익 정산은 백로그로 남긴다.

| 화면 가장자리 | 사무실 방향 화살표 (사무실이 화면 밖일 때) | 2순위 `확정` |
| 월드 | 패드 비용·게이지, 선반 수량, 트럭 주문 카드, 트럭 남은 수량, 플레이어 MAX | 1순위 |

### 12.2 주문서 큐 `1순위`

- 주문서는 상단 **오른쪽 끝부터** 쌓이고, 새 주문은 그 **왼쪽**에 붙는다 ([18번 확인 필요](#18-확인-필요-사항)).
- 화면에 보이는 슬롯은 5개 `임시`. 넘치는 주문은 왼쪽 끝에 `+n`으로 표시한다.
- 주문 카드 내용: 품목 색 아이콘 × 수량, 진행도, 상태 배지

| 상태 배지 | 의미 |
|---|---|
| 대기 | 아직 트럭이 배정되지 않음 |
| 🚚 도착 | 출고 트럭이 정차해 물건을 받는 중 |
| 📦 포장 중 | 포장대에서 작업 중 (Lv.4~) |
| ✅ 출발 | 완료 연출 후 카드가 사라지고 나머지 카드가 오른쪽으로 당겨짐 |

### 12.3 팝업

| 팝업 | 내용 | 우선순위 |
|---|---|---|
| 계약 팝업 | 회사 이름, 품목, 입고 물량, [계약] / 잠금 표시 | 1순위 |
| 이력서 UI | 후보 3명 카드(이름, 초상, 스탯, 고용금, 시급, [고용]) + 다음 갱신 타이머 + [새로고침 💰N] | 1순위 |
| 배치 현황판 UI | 알바 목록(이름, 현재 역할, 스탯, 시급, 미지급 표시) + 역할 버튼(해금된 역할만), 역할별 인원 수, [밀린 시급 지급] | 1순위 |
| 정산 결과 팝업 | 일차, 총 지급액, 미지급·퇴사 알바, 경고 | 1순위 |
| 레벨업 팝업 | 새 레벨 + 새로 해금된 항목 아이콘 목록 | 2순위 |
| 목표 달성 팝업 | Lv.11 도달 축하, "계속 플레이" 버튼 | 2순위 |

## 13. 튜토리얼

- 첫 플레이 시 아래 순서로 **바닥 유도선 + 화살표**를 띄워 안내한다. 각 단계는 조건을 만족하면 다음으로 넘어간다.
- 계약(1단계)은 진행에 반드시 필요하므로 `1순위`, 유도선·화살표 연출은 `2순위`.

| 단계 | 안내 | 완료 조건 |
|---|---|---|
| 1 | 사무실 계약 PC로 이동 → 회사 A 계약 | 계약 완료 (선반 4개 생성, 첫 입고 트럭 진입) |
| 2 | 트럭 옆 픽업 존에서 화물 집기 | 화물 1개 이상 들기 |
| 3 | 공용 보관소에 내려놓기 | 공용 보관소에 화물 있음 |
| 4 | 공용 보관소에서 집어 선반에 넣기 | 선반에 화물 1개 이상 |
| 5 | 첫 주문서 등장 → 선반 수거 존에서 꺼내기 | 주문 품목 들기 |
| 6 | 출고 트럭에 싣기 | 첫 주문 완료 |
| 7 | 현금 수거 | 현금 획득 |
| 8 | 사무실 고용 데스크에서 이력서 열람 → 알바 고용 → 역할 배치 | 알바 1명 배치 |

- 튜토리얼 중에는 첫 주문서를 5단계에 맞춰 1건만 생성한다.
- 튜토리얼 8단계의 **첫 고용은 고용금 면제**다 (첫 주문 수익만으로는 고용금이 부족하기 때문). 시급은 정상적으로 나간다.
- 첫 하루 정산 때 정산 팝업과 함께 미지급·퇴사 규칙을 1회 안내한다.
- Lv.4 포장소 해금 시 짧은 추가 안내(포장대 → 포장 존 → 트럭)를 1회 띄운다.

## 14. 2순위 시스템

### 14.1 저장 / 불러오기

- 저장 항목: 레벨, XP, 현금, 해금된 칸·구매한 시설, 업그레이드 단계, 계약 상태, 알바 목록(이름, 스탯, 시급, 역할, 미지급 금액), 일차·하루 진행 시간, 이력서 후보·갱신 타이머, 선반·공용 보관소·반품 랙 재고, 주문 큐, 플레이어가 들고 있는 화물, 튜토리얼 진행도
- 저장하지 않는 것: 이동 중인 차량. 불러오면 차량은 새로 진입한다.
- 자동 저장: 레벨업, 구매·고용, 주문 완료 시 + 앱이 백그라운드로 갈 때

### 14.2 업그레이드

- 플레이어 적재량 / 이동 속도 (Lv.3), 선반 용량 (Lv.5), 공용 보관소 용량 (Lv.6). 수치는 [5.1](#51-기본-수치-임시), [9.4](#94-비용표-임시) 참고.
- 선반 용량은 단계마다 선반 외형도 바뀐다.

### 14.3 돌발 이벤트 — 스케줄러 + 설비 고장 `확정`

- 하루(10분)당 최대 2회, 이벤트 사이 최소 3분 `임시`, 동시 발생 최대 1건.
- **설비 고장** (Lv.5~): 포장대 또는 입고 베이 중 하나가 멈추고 연기·느낌표 아이콘이 뜬다. 플레이어가 가서 2초 `임시` 게이지 존에 서면 수리된다.
- 애니메이션: `당황하기`

### 14.4 코스튬 변경

- 사무실 옷장(게이지 존)에서 UI를 열어 플레이어·알바의 코스튬 파츠(모자·조끼 등)를 바꾼다.
- 프로토타입은 기본 파츠 몇 개를 무료로 제공하고, 능력치는 없다.
- 핵심 루프 검증과 관계가 적으므로 2순위 중 가장 마지막에 구현한다.

### 14.5 디버그 메뉴 (신규)

- 테스트용으로 재화 추가, 레벨업, 게임 배속(×1/×2/×4), 주문 즉시 생성, 레벨별 도달 시간 로그 표시 기능을 둔다.
- `임시` 수치를 빠르게 검증하는 데 필요하다.

## 18. 확인 필요 사항

기획 Q&A에서 정해지지 않아 GDD에 **가정으로 적은** 항목이다. 확인 후 수정한다.

| # | 항목 | 현재 가정 | 관련 절 |
|---|---|---|---|
| 1 | 트럭 → 선반 직행 | **금지**. 트럭에서 꺼낸 화물은 공용 보관소에만 놓을 수 있음 (하차/분류 역할 구분을 살리기 위함) | 7.2 |
| 2 | 주문서 큐 방향 | 첫 주문이 **오른쪽 끝**, 새 주문은 왼쪽에 추가, 넘치면 왼쪽 끝 `+n` | 12.2 |
| 3 | 주문 구성 | 한 주문은 **한 회사 품목으로만** 구성 | 8.1 |
| 4 | 반품 검수 담당 | **플레이어 전용** (반품 알바 역할 없음) | 7.7 |
| 5 | 선반 용량 업그레이드 | 선반 개별이 아니라 **전체 선반 일괄** 적용 | 14.2 |
| 6 | 시작 선반 4개 | 회사 A 2종 × 2개씩으로 해석 | 7.3 |
| 7 | 계약 비용 | 없음 (레벨로만 제한) | 6.3 |
| 8 | 회사 이름 · 품목 테마 | 미정 (회사 A / B, 품목은 색으로만 구분) | 6.2 |
| 9 | 이력서 자동 갱신 시점 | 10분 주기를 **하루 시작 시점과 맞춤** (하루도 10분이라 정산 직후 갱신) | 11.1 |
| 10 | 알바 기본 수치 | 스탯 1 기준 적재 2개, 속도 2.5 m/s, 집기 간격 0.25초, 포장 4초 | 11.2 |

| 12 | 첫날 시급 · 지급 순서 | 첫날은 일한 시간 비율만큼 지급. 재화 부족 시 고용 순서대로 지급, 부분 지급 없음 | 11.7 |
| 13 | 밀린 시급 미리 지급 | 배치 현황판에서 다음 정산 전에 지급 가능 | 11.7 |
