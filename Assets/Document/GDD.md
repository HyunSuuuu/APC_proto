## 1. 게임 개요

### 1.1 한 줄 소개

작은 물류센터의 신입 센터장이 되어 택배를 직접 나르고, 주문을 처리해 번 돈으로 알바생을 고용하고 레벨업으로 구역을 늘려 센터를 자동화하는 **캐주얼 물류 경영 아케이드**.

### 1.2 기본 정보

| 항목 | 내용 |
|---|---|
| 장르 | 하이브리드 캐주얼 · 아케이드 경영 (자동 집기/내려놓기 방식) |
| 플랫폼 | 모바일 (Android / iOS) |
| 화면 방향 | **가로 고정** |
| 엔진 | Unity 6000.3 |
| 시점 | 쿼터뷰 고정 각도 3D |
| 아트 톤 | 귀여운 SD 캐주얼 — 2~3등신 캐릭터, 로우폴리 파스텔 톤. 작은 물류센터가 점점 커지는 성장 판타지 |
| 프로토타입 아트 | 임시 박스/프리미티브로 대체 가능. 화물 구분용 **테이프 색상**만은 처음부터 적용 |

### 1.3 프로토타입 목표

- **진행 목표**: Lv.1에서 시작해 **Lv.11 도달**(반품 구역 해금) 후 **반품 1개를 재포장해 선반에 넣으면** '프로토타입 완료'를 표시한다 (표시는 2순위). 이후 종료 조건 없이 계속 플레이.
- **목표 플레이 시간**: Lv.11 도달까지 약 25~35분 `임시`

### 1.4 검증 질문

프로토타입 플레이 테스트에서 아래 질문에 답할 수 있어야 한다.

| # | 검증 질문 | 확인 방법 |
|---|---|---|
| 1 | 화물을 자동으로 집고 쌓아 나르는 **손맛**이 기분 좋은가? | 집기 간격·스택 연출 조정 전후 비교 |
| 2 | 4단계 흐름(하차 → 분류 → 피킹 → 상차)이 **복잡하지 않고** 이해되는가? | 튜토리얼 없이/있이 첫 주문 완료까지 걸린 시간 |
| 3 | 알바를 고용해 **직접 하던 일이 자동화되는 쾌감**이 Lv.11까지 이어지는가? | 레벨별 플레이어 운반 비율 |
| 4 | Lv.4 **복합 주문** 전환이 자연스러운 난이도 상승인가? | Lv.4 전후 주문 처리 시간 |
| 5 | 성장 속도(레벨업·재화)가 너무 빠르거나 느리지 않은가? | 레벨별 도달 시간 로그 |
| 6 | **저금통 → 파트 정산** 구조가 "모아서 한 번에 받는" 기대감을 주는가? 시급 부담이 적절한가? | 파트별 정산액, 미지급 · 퇴사 발생 횟수 |

### 1.5 디자인 필러

1. **손으로 나르는 재미** — 모든 물류는 플레이어가 직접 해볼 수 있고, 자동 집기와 스택 연출이 기분 좋아야 한다.
2. **눈에 보이는 성장** — 구역이 늘고, 선반과 저금통이 차고, 알바가 늘어나는 변화가 화면에서 바로 보인다.
3. **한 단계씩 늘어나는 흐름** — 처음에는 단순한 흐름에서 시작해 레벨마다 단계(복합 주문, 2번째 회사, 반품)가 하나씩 추가된다.

## 2. 핵심 루프

### 2.1 사이클 (주문 1건 = 수익 1회)

```
[계약]  사무실 PC에서 회사와 계약 → 그 회사 품목의 분류 선반이 열림
   │
   ▼
① 입고    회사 트럭이 하차장에 자동 정차
② 하차    트럭 옆 픽업 존에서 화물을 집음 → 공용 보관소에 내려놓음
③ 분류    공용 보관소에서 집음 → 품목별 분류 선반(둘레 존)에 넣음
④ 피킹    주문서에 적힌 품목을 선반(둘레 존)에서 꺼냄
⑤ 상차    꺼낸 물건을 그 주문의 출고 트럭에 바로 실음 → 트럭 출발 (출발 순간 XP)
   │
   ▼
[출고 현금]  현금 존에 지폐 다발 생성 → 지나가며 수거 → **사무실 투명 저금통**에 모임
   │
   ▼
[파트 종료 정산]  파트(3분)가 끝나면 저금통 + 할당량 보너스 − 알바 시급 → 보유 재화 → 고용 · 업그레이드
   │
   ▼
[레벨업]  구역 추가 (레벨로 자동) → … → Lv.11 반품 구역 → 반품 재포장 → 선반
```

- **포장은 없다** (일반 주문 포장 삭제 `확정`). 모든 주문은 ④에서 꺼낸 물건을 출고 트럭에 **바로** 싣는다.
- **Lv.4~**: 복합 주문(품목 2종 이상)이 등장한다. 포장 없이 원물 그대로 싣는다.
- **Lv.11~**: 반품 구역이 열리고 입고 화물에 반품 상자가 섞인다 → 반품 대기 롤테이너 → 검수 테이블(**검수 + 재포장 한 번에**, 계약 품목 중 하나의 일반 상자가 됨) → 재포장 출구 → 선반 → 일반 주문으로 출고.
- **돈은 바로 쓰지 않는다**: 주운 현금은 저금통에 모이고, 파트가 끝나야 보유 재화로 옮겨진다 (→ [9.5](#95-저금통--파트-종료-정산-1순위)).

### 2.2 루프 계층

| 계층 | 주기 | 내용 |
|---|---|---|
| 마이크로 | 수 초 | 존에 들어가 자동으로 집기/내려놓기, 패드 게이지 채우기 |
| 메인 | 30초~1분 | 주문 1건 처리 → 현금 수거 → 저금통 |
| 파트 | 3분 (첫 파트 90초) `임시` | 파트가 끝나면 정산 팝업: 저금통 + 할당량 보너스 − 시급 → 보유 재화 → [9.5](#95-저금통--파트-종료-정산-1순위) |
| 메타 | 2~4분 | 레벨업 → 구역 추가 · 고용 · 업그레이드 → 처리량 증가 |

## 3. 조작 · 카메라

### 3.1 이동 — 가상 조이스틱 `1순위`

- **플로팅 조이스틱**: UI가 아닌 화면 아무 곳이나 터치하면 그 자리에 조이스틱이 생기고, 드래그한 방향으로 이동한다.
- 손을 떼면 즉시 정지하고 조이스틱이 사라진다.
- 드래그 거리 50% 미만은 걷기, 이상은 뛰기 애니메이션 (속도는 입력 크기에 비례).
- 최대 드래그 반경 80px `임시`

### 3.2 카메라 `1순위`

| 모드 | 동작 |
|---|---|
| **추적 (기본)** | 쿼터뷰 고정 각도(Pitch 45° `임시`, Yaw 45° `확정`)로 플레이어를 부드럽게 따라감 (감쇠 0.15초 `임시`) |
| **자유 이동** | HUD의 **카메라 버튼**으로 진입. 한 손가락 드래그로 맵 이동, 핀치로 확대·축소. **CCTV는 만들지 않는다** `확정` |

- 자유 모드에서는 조이스틱이 꺼지고, 카메라 버튼이 **'내 캐릭터로'** 버튼으로 바뀐다. 누르면 플레이어 위치로 0.4초 동안 부드럽게 복귀한다. `확정`
- 줌 범위: 카메라 거리 12~30, 기본 18 `임시`
- **이동 범위 제한** `2순위`: 해금된 부지 경계 밖으로 카메라가 나가지 않는다. 부지를 확장하면 경계도 함께 넓어진다.

## 4. 맵 · 레이아웃

### 4.1 원칙

- 배치는 **키보드 숫자 키패드 번호**로 부른다 (7 8 9 / 4 5 6 / 1 2 3). `확정`
- **하차장(4 · 2)** 은 트럭에서 물류를 내려놓는 **팔레트(공용 보관소)** 를 각자 가진다. **상차장(8 · 6)** 은 선반에서 바로 옮기므로 중간 보관소가 없다. `확정`
- 하차장 · 상차장 모듈은 **가장자리용**이다. 주차장은 모듈 칸 **바깥 가장자리에 붙어 있고**, 트럭은 주차장 바깥에 나타나 **후진으로 곧장** 들어온다 (앞머리는 바깥쪽, 뒷문은 건물 쪽). 나중에 모델이 들어오면 건물 벽의 **슬라이드 도어**에 트럭 화물칸 문만 보이게 붙는다. `확정`
- 트럭 방향: 4번(과 4번 왼쪽 확장) = 아래에서, 2번 = 왼쪽에서 (둘 다 빈 모서리 1번 쪽). 8번 = 오른쪽에서, 6번(과 6번 오른쪽 확장) = 위에서 (둘 다 빈 모서리 9번 쪽). `확정`
- 하차 · 상차 존은 트럭 뒷문 앞(모듈 안, 가장자리 쪽 끝)에 있다.
- 부지는 **모듈**(n × m 칸 프리팹)을 config(`SiteLayout`)에 적힌 위치 · 해금 레벨대로 붙여 만든다 (→ TechStack 5.7). 확장 = 잠긴 칸에 모듈을 붙이는 것.
- **잠긴 칸은 들어갈 수 없다.** 플레이어 · 알바는 열린 칸 안에서만 움직인다 (가장자리에서는 벽을 따라 미끄러짐).
- **다음에 해금될 구역 1곳만** 공사장 가설 울타리와 표지(`잠금해제 : LV 3`)로 보여준다. 그 밖의 잠긴 구역은 보이지 않는다. 해금 레벨이 되면 울타리가 사라지고 모듈이 팝 연출과 함께 **뿅 나타난다**. `확정`
- 부지 바깥 바닥(초록 Ground)은 임시이며 나중에 지운다.
- 확장 칸은 이미 열린 칸과 붙어 있어야만 해금된다 (섬처럼 떨어진 칸 없음).
- 여러 칸을 **한 번에 해금되는 묶음**으로 만들 수 있다. 예: 선반 구역 모듈 + 옆의 **빈 타일**(바닥만 있는 칸)을 묶으면 ㄱ자 구역이 한꺼번에 열린다. 묶음은 대표 칸의 해금 레벨을 쓴다. `확정`

### 4.2 부지 그리드 `임시`

- 칸 한 변 **10m** (칸 사이 이동 약 2.5초). 카메라는 쿼터뷰(Yaw 45°)라 부지는 화면에서 **마름모(아이소메트릭)** 로 보인다. `확정` (Yaw 0° 정면 배치는 시험해 본 뒤 제외)

```
 키패드 번호 (행 R · 열 C)

            C0            C1            C2            C3            C4
  R1                    ■ 7 사무실     ■ 8 상차장  🚚← (9: 없는 칸)  
  R2   🔒 E2 하차장  ■ 4 하차장     ■ 5 선반 A    ■ 6 상차장    🔒 E3 상차장
        (4번 왼쪽)    +팔레트                                      (6번 오른쪽)
  R3               (1: 없는 칸)    ■ 2 하차장    🔒 E1 선반 B   🔒 E4 반품 (Lv.11)
                   🚚↑ 4번 · 🚚→ 2번  +팔레트     (3번)         (3번 오른쪽)

  ■ = 시작 부지   🔒 = 잠긴 확장 칸 (다음 해금 1곳만 울타리로 보임)
  6번 · E3 트럭은 위(9 쪽)에서, 8번 트럭은 오른쪽(9 쪽)에서 들어온다
```

| 칸 | 키패드 | 내용 | 해금 레벨 `임시` |
|---|---|---|---|
| 시작 부지 | 7 · 8 · 4 · 5 · 6 · 2 | 사무실, 상차장 2곳(8 · 6), 하차장 2곳 + 팔레트(4 · 2), 선반 구역 A(5) | Lv.1 |
| E1 | 3 | 선반 구역 B (**회사 B 선반**) | Lv.3 |
| E2 | 4번 왼쪽 | 하차장 3 (+팔레트, 트럭은 아래에서) | Lv.5 |
| E3 | 6번 오른쪽 | 상차장 3 (트럭은 위에서) | Lv.7 |
| E4 | 3번 오른쪽 | 반품 구역 (반품 대기 롤테이너, 검수 테이블) | **Lv.11** |

- 확장은 **레벨만으로** 열린다. 비용 · 해금 패드가 없고, 레벨이 되는 순간 자동으로 해금된다. `확정`
- 칸 하나는 바닥 타일 + 내벽/외벽 모듈 묶음이다. 프로토타입에서는 **벽 없이 바닥 모듈만** 붙인다. 이동 제한은 칸 판정으로 동작하므로 벽은 외형 작업(M10) 때 모듈에 넣는다. `임시`

### 4.3 사무실 `확정`

- 계약 PC(계약 · 고용 · 배치 탭), **투명 저금통**이 모여 있는 곳이다.
- **사무실 = 최초 스폰 지점**이다. `확정`
- **순간이동은 없다** — 플레이어가 걸어서 가야 한다.
- 사무실 위치 화살표(사무실이 화면 밖일 때 가장자리 화살표)는 `2순위` · 논의 중 (→ [12.1](#121-hud-1순위)).

## 5. 플레이어

### 5.1 기본 수치 `임시`

| 항목 | 기본값 | 업그레이드 (2순위) |
|---|---|---|
| 이동 속도 | 4.0 m/s | 4.5 → 5.0 → 5.5 |
| 최대 적재 수 | 5개 | 7 → 9 → 12 |
| 집기/내려놓기 간격 | 0.15초 / 1개 | - |

### 5.2 상호작용 존 `1순위`

존은 두 종류다. 모든 존은 바닥 마킹으로 표시한다.

| 종류 | 동작 | 해당 존 |
|---|---|---|
| **운반 존** | 존 안에 있는 동안 간격마다 1개씩 자동으로 집거나 내려놓음 | 하차 존, 공용 보관소, 선반 둘레 존, 출고 트럭 상차 존, 반품 대기 롤테이너, 검수 테이블 (+ 현금 존은 지나가기만 해도 흡수하는 예외) |
| **게이지 존** | 존 위에 서 있으면 게이지가 차고, 다 차면 동작 실행 | 업그레이드 패드, 계약 PC(계약 · 고용 · 배치), 검수 |

- **상호작용은 존 안에서 멈춰 있을 때만 일어난다.** 움직이면 즉시 멈춘다. 지나가다 실수로 구매·하차하는 일을 막는다. `확정`
  - **운반 존**: 멈춘 뒤 0.5초 `임시`가 지나면 첫 상자를 바로 옮기고, 이후 간격마다 1개씩. 대기 중에는 존 바닥 색이 점점 밝아진다.
  - **게이지 존**: 따로 기다리지 않고 **멈추는 순간부터 게이지가 찬다** (게이지가 곧 대기 시간). 사무실 시설(계약 PC)은 0.5초 `임시` → 멈추고 0.5초 뒤 바로 열린다.
  - 알바도 작업 지점(슬롯)에 도착한 뒤 0.5초 `확정` 기다린다 (알바 전용 `StaffRules.interactionDelay`, [11.4](#114-작업-ai-상태-머신-1순위)).
- 게이지 존에서 벗어나면 진행이 **멈추고 유지된다** (구매 패드에 넣은 재화 유지). 다시 올라서면 이어서 진행.
- 운반 존에서 집기와 내려놓기가 둘 다 가능하면 **내려놓기를 우선**한다.

### 5.3 운반 규칙 `1순위`

- 들고 있는 화물은 머리 위로 쌓아서 보여준다. 최대 적재 수에 도달하면 스택 위에 **MAX** 표시.
- **품목이 다른 화물을 섞어서 들 수 있다.**
- 존은 자기가 받는 화물만 가져간다. 예를 들어 빨강 선반 둘레 존에서는 빨강 상자만 빠져나가고, 나머지 상자는 아래로 내려앉아 다시 정렬된다.
- 받는 존이 없는 화물은 계속 들고 다닌다 (버리기 기능 없음).
- **수요 기반 집기**: 선반 둘레 존에서는 현재 처리 중인 주문에 **필요한 품목을 필요한 수량만큼만** 집는다 (과집기 방지). → [8.4](#84-수요-계산)
- **상호작용 쿨타임** (플레이어만): 한 존에서 **내려놓기 ↔ 집기로 바뀔 때 0.5초** `임시` 쉰다. 다 내려놓고 바로 다른 물건을 집어 버리는 일을 줄인다. `확정`
- **작업 고정** (플레이어만): 지금 하는 일의 화물을 들고 있는 동안에는 **그 일만** 할 수 있다. 들고 있는 화물과 출처(트럭 / 팔레트 / 선반)가 다른 화물은 다 내려놓기 전까지 집지 않는다. `확정`
  - 예: 팔레트에서 분류용으로 집은 화물을 들고 선반에 가면, 그 선반 품목만 내려놓고 주문용 화물은 집지 않는다.
  - 이유: 들고 있는 화물마다 어디로 갈지 UI로 표시하지 않으므로, 서로 다른 일의 화물이 섞이면 플레이어가 헷갈린다.
- **가이드 화살표** (플레이어만): 들고 있는 화물이 가야 할 곳을 가리킨다 (트럭 화물 → 가장 가까운 팔레트, 팔레트 화물 → 그 품목 선반, 선반 화물 → 그 품목이 필요한 출고 트럭). **손이 비면 표시하지 않는다.** 목표가 화면 안이면 목표 위에서 아래를 가리키며 통통 튀고, 화면 밖이면 화면 가장자리에서 목표 쪽을 가리키며 늘었다 줄었다 한다. `확정`
- 쿨타임 · 작업 고정 · 화살표는 **알바에게 적용하지 않는다** (알바는 역할대로 움직인다). `확정`

## 6. 화물 · 계약

### 6.1 화물 데이터 `1순위`

| 필드 | 내용 |
|---|---|
| 품목 ID | 품목 종류. **테이프 색상**으로 구분 |
| 소속 회사 | 회사 A / 회사 B |
| 상태 | 일반 / 반품 (Lv.11~) / 재포장 (반품 검수 후) |
| 크기 | 모두 동일 (운반 슬롯 1칸). 종류마다 **디자인만 다르다** |

### 6.2 회사 · 품목 `임시`

| 회사 | 계약 시점 | 품목 수 | 품목 (테이프 색) | 입고 트럭 적재량 | **계약 단가** (상자 1개) |
|---|---|---|---|---|---|
| 회사 A | Lv.1 (튜토리얼) | 2종 | A1 빨강, A2 파랑 | 8개 | 10 |
| 회사 B | Lv.7 | 3종 | B1 노랑, B2 초록, B3 보라 | 10개 | 14 |

- 단가는 **회사(계약)마다 하나**다. 품목별 단가 · 복합 주문 배율은 없다 (→ [8.5](#85-주문-보상-임시)). `확정`

- 회사 이름은 미정 (임시: 회사 A / 회사 B). 테이프 색은 색약 사용자를 위해 상자 옆면에 품목 아이콘도 함께 표시하는 것을 권장.

### 6.3 계약 (기본 계약 체결) `1순위`

- **계약해야 그 업체 차량이 들어온다** — 루프의 맨 앞. 프로토타입 계약은 1~3건. 업체 비교 · 계약 슬롯 관리(계약 UI 상세)는 이후로 미룬다.
- 사무실 **계약 PC**(게이지 존, 임시로 '결제 서류' 상호작용)에 서면 계약 팝업이 열린다.
- 팝업 내용 (계약 탭): 회사 카드 — 회사 이름, 취급 품목(색 아이콘), `입고 트럭 : N` / `단가 : N` 두 줄 (버튼처럼 보이는 띠는 없음). **버튼 대신 도장**: 오른쪽 아래 도장(고용 탭과 같은 도장, → 11.1)을 회사 카드에 끌어다 찍으면 계약한다 → 붉은 `[ 계약 ]` 자국 + 회색 필터를 잠깐 보여 준 뒤 팝업이 닫히고 선반이 생긴다. `확정` (2026-11-11)
- 아직 계약할 수 없는 회사는 이유를 정보 아래 붉은 글자로 표시하고, 도장을 찍으면 카드가 흔들리며 이유가 뜬다: `Lv.7 해금` / `선반 구역 B 필요`(그 회사 선반 구역이 아직 잠김) / `선반 자리 부족` / `이미 계약함`.
- **회사마다 자기 선반 구역**이 있다: 회사 A = 선반 구역 A(5번), 회사 B = 선반 구역 B(3번, Lv.3 해금). 그 구역이 열려 있어야 계약할 수 있다. `확정`
- 계약하면:
  1. 그 회사 선반 구역에 **품목마다 분류 선반 1개**가 팝 연출과 함께 생성된다.
  2. 그 회사의 입고 트럭이 오기 시작한다.
  3. 그 회사 품목으로 된 주문이 생성되기 시작한다.
- 계약 비용은 없다 (레벨로만 제한).

## 7. 물류 흐름 상세

### 7.1 입고 — 트럭 도착 · 정차 `1순위`

- 입고 트럭은 **빈 하차장**에 정차한다. 동시 정차 수 = 하차장 수 (시작 2: 4번 · 2번).
- 하차장 모듈의 주차 칸은 **모듈 칸 바깥 가장자리**에 붙어 있다. 트럭은 주차 칸 바깥쪽에 나타나 **후진으로 곧장 주차**하고(앞머리는 바깥쪽, 뒷문은 건물), 다 비면 앞으로 나가 사라진다. 도로 주행 연출은 없다 — 모듈이 어디에 붙든 혼자 동작하게 하기 위해서다. 하차 존은 트럭 뒷문 앞(모듈 안 가장자리)에 있다. `확정`
- 출고 트럭도 같은 방식으로 **상차장**(8번 · 6번)을 쓴다.
- 같은 모서리를 향하는 두 주차장(4 · 2는 1번 쪽, 8 · 6은 9번 쪽)은 트럭이 겹치지 않게 주차 칸을 서로 반대쪽으로 비켜 둔다.
- 트럭 회사는 계약한 회사 중에서 고른다 (가중치 → [7.8](#78-교착-방지-규칙)).
- 트럭 뒷문 앞 **하차 존**(하차 지점)에서 플레이어나 하차 알바가 화물을 하나씩 꺼낸다 (지금 방식 유지 `확정`). 화물이 다 빠지면 트럭이 출발하고, 4초 `임시` 뒤 다음 트럭이 들어온다.
- 트럭에 남은 수량은 트럭 위 숫자로 표시한다.
- 시작 시 트럭에서 상자를 꺼내는 애니메이션: `트럭에서 상자 내리기`.
- 에셋: 입고 차량 = **대형 화물차**, 하차장 주차 칸 = **대형 주차장**.
- **차량 대기열** `2순위`: 베이가 모두 차 있으면 다음 트럭이 도로에서 대기하고, 대기 차량 수를 표시한다.

### 7.2 하차 → 공용 보관소 `1순위`

- 트럭에서 꺼낸 화물은 **공용 보관소에만** 내려놓을 수 있다 (트럭에서 선반으로 바로 넣기 불가 — [18번 확인 필요](#18-확인-필요-사항)).
- 공용 보관소는 품목을 섞어서 보관하는 바닥 팔레트 구역이다. **하차장마다 하나씩** 하차장 모듈 안에 있다. 용량은 팔레트마다 20개 `임시` (업그레이드로 30 → 40).
- 공용 보관소는 팔레트를 두른 **둘레 존 하나**로 상호작용한다 (선반과 같은 방식). 근처에서 멈추면 **트럭 화물 내려놓기를 먼저** 하고, 내려놓을 것이 없으면 집는다. `확정` (v0.3: 내려놓기 · 집기 존 분리 → 하나로)
- 집을 때는 **넣을 선반에 빈자리가 있는 품목만, 빈자리 수만큼** 집는다 (이미 들고 있는 같은 품목 수는 뺀다). 쓸모없는 화물을 들고 다니지 않게 한다. `확정`
- 공용 보관소가 가득 차면 트럭 픽업이 사실상 멈추고, 트럭은 화물이 남아 있는 한 베이를 비우지 않는다.

### 7.3 분류 → 분류 선반 `1순위`

- 선반 1개는 **품목 1종 전용**이고, **품목마다 선반은 1개뿐**이다 (같은 품목 선반을 더 만들지 않는다). 선반 위에 품목 색 아이콘을 표시한다. `확정`
- 선반은 **정사각형**이고 **둘레에 존이 하나** 있다. 근처(둘레 존)에서 0.5초 멈추면 **내려놓기를 먼저** 하고(그 품목 · 공용 보관소에서 집은 화물), 내려놓을 것이 없으면 **주문 수요만큼 집는다**. `확정`
- 공용 보관소에서 집은 화물만 선반에 넣을 수 있다.
- 용량: 기본 10 → 선반 용량 업그레이드 `2순위` · 논의 중 (외형은 10 → 15 한 단계만 정해짐)
- 적재량 외형: 선반 칸에 **실제 상자가 하나씩 올라간다** (칸이 차는 모습 = 빈/절반/가득). `확정`
- 선반 위 수량 표시 (예: `7/10`)
- 시작 선반: 회사 A 계약 시 **2개** (A1, A2). 선반 공간을 늘리는 방법은 선반 용량 업그레이드뿐이다.

### 7.4 피킹 `1순위`

- 플레이어나 피킹 알바가 선반 둘레 존에서 주문에 필요한 품목을 꺼낸다 (수요 기반 → [8.4](#84-수요-계산)).
- 꺼낸 물건을 출고 트럭 상차 존에 **바로** 싣는다 (모든 레벨).

### 7.5 포장 — **삭제** `확정`

- 포장대 · 포장 구역 · 포장 상자는 없다. 복합 주문도 원물 그대로 싣는다.

### 7.6 상차 → 출고 · 현금 `1순위`

- 출고 트럭은 **주문 1건당 1대**다. 상차장이 비면 가장 오래된 미배정 주문의 트럭이 들어와 **정차해서 기다린다** → [8.3](#83-주문--트럭-배정).
- 트럭 위에 주문 카드를 띄운다.
- 트럭 상차 존은 **자기 주문에 해당하는 것만** 받는다 — 주문 품목 원물을 남은 수량만큼. 재포장한 반품은 일반 상자가 되어 선반을 거쳐 주문으로 출고된다 (→ 7.7).
- 주문이 충족되면 트럭이 출발한다. **출발하는 순간** ① XP를 주고 ② 그 상차장의 **현금 존**에 `실린 상자 수 × 계약 단가`만큼 지폐 다발이 쌓인다. `확정`
- 현금 존은 **상차장마다 상차 존 바로 옆**(상차장 모듈 안)에 있다. 바닥 마킹으로 표시한다. `확정`
- 플레이어가 현금 존 반경 **1.5m** `임시` 안에 들어오면 다발이 플레이어에게 빨려 들어온다. **멈출 필요 없이 지나가기만 해도 흡수한다** (받는 행동이라 "멈춰야 상호작용" 규칙의 예외). `확정`
- 다발이 플레이어에게 닿으면 **달러 아이콘이 HUD 저금통 아이콘으로 포물선을 그리며 날아가고**, 도착할 때 저금통 칸이 오른다 (임시 이미지 `Art/Temp/Dollor`). `확정` (2026-11-12)
- **주운 돈은 바로 쓰지 않고 사무실 저금통에 모인다** (HUD 저금통 칸이 오름) → 파트 종료 정산에서 보유 재화로 옮겨진다 (→ [9.5](#95-저금통--파트-종료-정산-1순위)). `확정`
- 지폐 다발은 **10원당 1개**, 나머지는 마지막 다발에 포함한다 (예: 52원 = 6개). 보이는 다발은 **최대 40개**(4 × 5 × 2층 `임시`), 넘으면 맨 위에 `+금액` 숫자로 표시한다. `확정`
- **줍지 않은 현금은 사라지지 않고** 다음 파트로 넘어간다. **알바는 현금을 줍지 않는다.** `확정`
- 애니메이션: `트럭에 상자 싣기`

### 7.7 반품 접수 · 검수 · 재포장 → 선반 `1순위` (Lv.11 해금, 3번 오른쪽)

```
입고 트럭(반품 섞임) → 반품 대기 롤테이너 → 검수 테이블 (검수 + 재포장 한 번에) → 계약 품목 중 하나의 일반 상자 → 재포장 출구 → 선반 → (일반 주문으로 출고)
```

- Lv.11(반품 구역 해금)부터 입고 상자마다 **10%** 확률 `임시`로 **반품 상자**가 섞여 도착한다 (`LogisticsConfig.returnChance`). 반품 상자 = 회색 상자 + 빨간 띠. `확정` (2026-11-12)
- 반품 상자는 팔레트 · 분류 선반에 넣을 수 없고 **반품 대기 롤테이너**(반품 구역, 12개 `임시`)에만 내려놓는다. **하차 알바도 반품은 롤테이너로 나른다.** 분류 알바는 반품을 건너뛴다. `확정`
- **검수 테이블**: 플레이어가 존에 멈춰 서 있으면 롤테이너의 반품 상자를 하나씩 검수하고 **재포장까지 한 번에** 한다 (상자 1개당 게이지 1.5초 `임시`, XP +5). 일반 주문 포장은 여전히 없다. `확정`
- **재포장 = 품목이 바뀐다**: 원래 품목과 무관하게 **지금까지 계약한 품목 중 선반에 자리가 남은 품목 하나**(무작위)의 일반 상자(흰 상자 + 품목 테이프)가 되어 테이블 옆 **재포장 출구**(6개 `임시`)에 쌓인다. 자리 = 선반 빈자리 − 선반으로 들고 가는 수 − 분류 알바 예약 − 출구에서 기다리는 수. 자리가 남은 품목이 없거나(플레이어가 예약보다 더 집은 경우 포함) 출구가 가득 차면 **자리가 빌 때까지 검수가 멈춘다**. `확정` (2026-11-12)
- 출구의 상자는 **일반 화물**이다: 플레이어 · **분류 알바**가 그 품목 선반에 빈자리만큼 옮기고, 이후 일반 주문으로 출고된다. 따로 실리는 재포장 상자나 '반품 재출고 수입'은 없다. `확정` (2026-11-12)
- 재포장한 상자가 **처음으로 선반에 들어가면** 프로토타입 목표 달성 (→ [1.3](#13-프로토타입-목표)). `확정`
- 폐기 분기는 프로토타입 이후로 미룬다.
- 애니메이션: `물품 검수하기` / `바코드 스캔하기`
- 프로토타입에서 검수는 **플레이어 전용**이다 (반품 담당 알바 역할 없음 — [18번 확인 필요](#18-확인-필요-사항)).

### 7.8 교착 방지 규칙 `1순위`

특정 품목이 선반·공용 보관소에 가득 쌓였는데 주문은 다른 품목만 요구하면 흐름 전체가 멈출 수 있다. 이를 막기 위해 다음 규칙을 둔다.

| 규칙 | 내용 |
|---|---|
| 입고 구성 가중치 | 입고 트럭에 실을 품목은 `(대기 주문의 수요 − 현재 재고)`가 클수록 확률이 높다. 품목마다 최소 가중치 10%를 보장한다. |
| 주문 생성 가중치 | 재고(선반 + 공용 보관소)가 많은 품목일수록 주문에 나올 확률이 높다. |
| 트럭 회사 선택 | 입고 트럭 회사도 위 품목 가중치의 합으로 고른다. |

## 8. 주문 시스템

### 8.1 주문서 `1순위`

- 주문서 내용: **품목별 수량** (예: 빨강 × 3, 파랑 × 2). 제한 시간 없음.
- 주문은 한 회사의 품목으로만 구성한다 (회사 섞임 없음 — [18번 확인 필요](#18-확인-필요-사항)).

| 구간 | 주문 종류 | 구성 `임시` |
|---|---|---|
| Lv.1~3 | 단일 주문만 | 품목 1종 × 2~4개 |
| Lv.4~6 | 단일 40% / 복합 60% | 복합: 품목 2종 × 각 1~3개 |
| Lv.7~ | B사 주문 추가 | 복합: 품목 2~3종 × 각 1~3개 (최대 합계 8개) |

### 8.2 주문 생성 · 큐

- 주문은 일정 간격으로 생성되어 큐에 쌓인다: Lv.1~3 15초, Lv.4~ 12초 `임시`.
- **계약하는 순간 첫 주문 1건이 바로 생긴다** (목표가 처음부터 보이도록). 이후는 위 간격대로. `확정`
- 큐에 쌓인 주문이 8건 `임시`이면 생성을 멈춘다 (무한 누적 방지).
- 큐는 화면 상단에 표시한다 → [12.2](#122-주문서-큐-1순위).

### 8.3 주문 — 트럭 배정

- 상차장이 비면 **가장 오래된 미배정 주문**의 출고 트럭이 들어와 정차한다 (진입 3초 `임시`).
- 동시에 처리할 수 있는 주문 수 = 상차장 수 (시작 2: 8번 · 6번).
- 플레이어가 처리할 주문을 고르지 않는다 (자동 배정).

### 8.4 수요 계산

`현재 수요` = 정차 중인 트럭 주문의 남은 수량 − 플레이어/알바가 이미 들고 있거나 예약한 수량

- 선반 둘레 존의 수요 기반 집기, 피킹 알바의 작업 대상 선택, 교착 방지 가중치가 모두 이 값을 사용한다.
- 알바가 작업을 고르면 해당 수량을 **예약**해서 여러 알바가 같은 수요를 중복으로 가져가지 않게 한다.
- **예약 3역할**: 하차 = 정차 트럭의 남은 화물, 분류 = 선반 빈자리(품목별), 피킹 = 주문 수요. 예약 수량의 한도는 알바의 남은 적재 수다. `확정`
- **출발 · 도착**: 알바는 집으러 **출발할 때** 가져갈 만큼 예약하고, **도착하면** 푼다. 그 뒤로는 들고 있는 수가 예약을 대신해 잡는다. `확정`
- **플레이어**: 공용 보관소 집기 = 선반 빈자리 − 들고 가는 수 − 분류 예약이라서, 예약된 만큼은 플레이어도 덜 받는다. 하차는 플레이어가 트럭에서 꺼내는 데 제한이 없다. `확정`

### 8.5 주문 보상 `임시`

| 항목 | 단일 주문 | 복합 주문 |
|---|---|---|
| 출고 현금 (트럭 출발 순간, 현금 존) | **실린 상자 수 × 계약 단가** | 실린 상자 수 × 계약 단가 (배율 없음) |
| XP (트럭 출발 순간) | +10 | +20 |

예) 회사 A(단가 10) 상자 3개 = 30 / 회사 A 상자 4개(복합) = 40 / 회사 B(단가 14) 상자 5개 = 70
- 복합 주문 배율(×1.3)은 삭제 `확정`. 복합 주문은 XP만 더 준다.

## 9. 경제 · 건설

### 9.1 재화 `1순위`

- 재화는 **현금 1종**이다 (유료 재화는 백로그). 다만 돈이 **두 칸**에 있다 `확정`:
  - **보유 재화**: 실제로 쓸 수 있는 돈. 시작 50 `임시`.
  - **저금통**: 이번 파트에 주운 돈. **쓸 수 없다.** 파트 종료 정산 때 보유 재화로 옮겨진다.
- 획득 경로: 출고 트럭 출발 → 현금 존 → 수거 → 저금통 → 파트 종료 정산 → 보유 재화 (→ [7.6](#76-상차--출고--현금-1순위), [9.5](#95-저금통--파트-종료-정산-1순위))
- 사용처 (보유 재화만): 알바 고용금, 알바 시급(파트 정산에서 차감), 업그레이드 (구역은 레벨로만 열리므로 돈이 들지 않는다)

### 9.2 구매 패드 `1순위` (업그레이드 등에 사용)

- 패드에 **아이콘 + 비용**과 게이지 링을 표시한다. (v1: 바닥 + 원형 게이지, 가운데 **남은 금액**, 아래 이름. 아이콘은 아트 작업 때)
- 돈은 **플레이어만** 낸다 (알바가 패드 위를 지나가도 진행되지 않음).
- 패드 위에 서 있으면 **보유 재화**가 조금씩 들어가고 게이지가 찬다 (**저금통 돈은 쓸 수 없다** `확정`). 모두 들어가는 데 1.5초 `임시` (금액이 커도 시간은 같음).
- 재화가 부족하면 가진 만큼만 들어가고 게이지가 멈춘다. 들어간 금액은 유지된다.
- 게이지가 다 차면 효과가 적용되고(시설 생성 등) 패드는 사라진다.
- 패드는 해금 레벨이 되기 전에는 **보이지 않고**, 레벨이 되는 순간 **팝 연출과 함께 나타난다**. `확정`
- **업그레이드 패드** `2순위`: 단계가 오르면 비용이 갱신된 채 그 자리에 남는다.

### 9.3 구역 추가 `1순위`

- **구역 단위로 통째로 생긴다** (바닥 · 벽 이어 붙이기 아님). 지역(맵)은 1개 — 지역 이동은 보류. `확정`
- 확장 칸(구역)은 **레벨이 되면 자동으로 해금**된다 (비용 · 패드 없음, → [4.2](#42-부지-그리드-임시)). `확정`
- 다음 해금 구역 1곳은 **공사장 가설 울타리** + 표지 `잠금해제 : LV N`으로 미리 보여준다. 레벨이 되면 울타리가 사라지고 모듈이 팝 연출로 나타난다. `확정`
- 열린 칸과 붙어 있는 칸만 해금된다 (섬 금지).
- 해금하면 네비메시를 다시 굽는다.

### 9.4 비용표 `임시`

| 항목 | 비용 |
|---|---|
| 확장 칸 | 없음 (레벨로 자동 해금) |
| 알바 고용금 | 스탯 총합 × 15 → [11.2](#112-스탯-1순위) |
| 알바 시급 (파트 정산마다) | 스탯 총합 × 4 → [11.7](#117-파트-정산--시급-1순위) |
| 플레이어 적재량 업그레이드 (3단계) | 100 / 200 / 350 |
| 플레이어 이동 속도 업그레이드 (3단계) | 100 / 200 / 350 |
| 선반 용량 업그레이드 (전체 선반 적용) | 논의 중 |
| 공용 보관소 용량 업그레이드 (2단계) | 150 / 300 |

### 9.5 저금통 · 파트 종료 정산 `1순위`

**돈 흐름** `확정`
1. 출고 트럭 출발 → 현금 존에 지폐 다발 생성 (`현금 존 금액 += 실린 상자 수 × 계약 단가`)
2. 현금 존에 쌓인다 (보이는 다발 최대 40개, 넘으면 맨 위 `+금액`). 줍지 않아도 사라지지 않는다.
3. 플레이어가 반경 안에 들어오면 수거 → **저금통** 금액 증가
4. 돈을 쓸 때는 **보유 재화만** 줄어든다 (저금통 돈은 못 씀)
5. 파트 종료 → `보유 재화 += 저금통 + 할당량 보너스 − 알바 시급`, 저금통 = 0 → **정산 팝업**
6. 남은 현금 존 돈은 다음 파트로 넘어간다

**시간 흐름 (파트)** `1순위` `확정`
- 파트 길이 고정 **180초**, **첫 파트만 90초** `임시`. 일시정지 · 팝업 중에는 멈춘다. 출퇴근 · 출입구 없음.
- HUD에 **파트 남은 시간**을 표시한다.

**사무실 투명 저금통** `1순위`
- 이번 파트에 모은 돈을 사무실의 **유리 저금통**으로 보여준다. 동전이 **10단계**로 차오르고 정산 때 비워진다.
  - v1(임시 프리미티브): 사무실 한쪽에 사람 키만 한 **반투명 원통** + 안에 **금색 동전 층**이 10단계로 높아짐, 위에 금액 글자, 돈이 들어올 때마다 살짝 튐. `확정`
- 가득 기준 = `MAX(300, 직전 파트 정산액 × 1.2)` `임시`

**정산 팝업** `1순위`
- 출고 수입 · 할당량 보너스 · 알바 시급 · 합계 → **[확인]** 을 누르면 다음 파트. 팝업 중에는 게임이 멈춘다.
- 연출 `확정`: 팝업의 줄마다 금액이 차례로 올라간다 → [확인]을 누르면 HUD 저금통 숫자가 줄면서 보유 재화가 카운트업되고, 사무실 저금통이 비워진다.

**할당량** `2순위`
- 파트마다 목표 출고 대수 `2 + Lv ÷ 3`(내림) 대 `임시`. 달성하면 정산 때 보너스 = 그 파트 저금통의 20% `임시`.

**주요 파라미터 (제안값)**

| key | 값 | 설명 |
|---|---|---|
| `part_length_sec` | 180 | 파트 길이 (초) |
| `first_part_length_sec` | 90 | 첫 파트만 짧게 |
| `start_money` | 50 | 시작 보유 재화 |
| `cash_bundle_value` | 10 | 지폐 다발 1개 금액 |
| `cash_pile_cols × rows × layers` | 4 × 5 × 2 | 보이는 다발 최대 40개 |
| `collect_radius` | 1.5 | 수거 시작 거리 (m) |
| `piggy_step_count` | 10 | 저금통 높이 단계 |
| `piggy_full_min` / `piggy_full_ratio` | 300 / 1.2 | 가득 기준 |

## 10. 레벨 · 해금

### 10.1 경험치 `1순위`

## 11. 알바생

### 11.1 고용 (계약 PC 고용 탭) `1순위`

- **고용 데스크는 없다.** 사무실 **계약 PC** 팝업에 `계약 | 고용` **탭**이 있고, 고용 탭에서 고용한다. 팝업을 열면 계약 전에는 계약 탭, 첫 계약 뒤에는 고용 탭이 열린다. `확정` (2026-11-11, 고용 데스크 · 바로 고용 대체)
- 고용 탭 `확정`
  - **후보 3명** `임시`을 카드로 보여준다: 이동 속도 · 적재량(파생값 m/s · 개수 함께) · 고용금 · 시급. 보유 재화가 모자란 후보는 고용금을 빨간 글자로.
  - 위 왼쪽에 `알바 n/최대 · 보유 재화`, 위 오른쪽에 **다음 후보 교체까지 남은 시간**(= 파트 남은 시간)과 그 아래 **[새로고침]**(무료) 버튼.
  - 오른쪽 아래 **도장을 끌어 후보 카드에 놓으면** 고용한다. 도장은 평소 앞모습, 들면 윗모습이고, 찍을 때 꾹 누르듯 조금 커졌다 돌아와 카드 위에 잠깐 머문 뒤 제자리로 간다 (연출 값은 `StampConfig` 에셋에서 조절). 고용한 카드에는 붉은 `[ 고용 ]` 도장 자국이 대각선으로 크게 찍히고 불투명한 회색 필터가 덮인다 (다음 교체까지 그대로 남음). 도장은 계약 탭과 같이 쓴다 (→ 6.3).
  - 고용할 수 없으면(보유 재화 부족 / 최대 인원 / 이미 고용함) 도장이 제자리로 돌아가고 카드가 좌우로 흔들리며 사유가 뜬다.
  - 후보는 **파트가 바뀔 때마다** 자동으로, 또는 [새로고침]으로 3명 모두 새로 뽑힌다.
  - 고용해도 팝업은 **열린 채**다 (연달아 고용 가능). 팝업 중에는 게임이 멈추므로 알바 등장 연출은 닫은 뒤에 이어서 보인다.
- 고용금은 **보유 재화**에서만 낸다. 고용하면 XP +5 ([10.1](#101-경험치-1순위)).
- 고용할 때 **외형(코스튬)과 스탯을 랜덤으로** 정한다. 코스튬은 **바꿀 수 없다**(입고 온 그대로). `확정` `2순위`(외형 랜덤)
- 고용하면 알바 1명이 **계약 PC 책상 건너편**(PC 존 바로 앞)에 팝 연출과 함께 나타나고, **비어 있는 역할에 자동 배정**된다 (하차 → 분류 → 피킹 순으로 빈 역할, 다 차면 인원이 가장 적은 역할). `확정`
- 알바 외형은 M6에서 **임시 캡슐**(높이 1.2) + **역할별 색**(하차 주황 · 분류 청록 · 피킹 보라, 색은 `StaffRules`에서 조정)이다. 역할이 바뀌면 색도 바뀐다. `확정` `임시`
- 최대 알바 수는 레벨에 따라 늘어난다 ([10.3](#103-레벨-테이블-임시)). 최대 인원이면 고용 탭에서 도장을 찍어도 `최대 인원`으로 막힌다.
- **해고** `확정` (2026-11-11, 2순위 → M6-6에 포함): 계약 PC 배치 탭에서 언제든 해고할 수 있고, 빈자리는 다시 고용한다. 고용금은 돌려받지 않는다. 해고한 알바는 명단에서 바로 빠지고, 들고 있던 화물을 배달한 뒤 PC 앞으로 걸어가 사라진다.

### 11.2 스탯 `1순위`

알바는 **이동 속도 · 적재량** 2가지 스탯을 가진다 `확정`. 모든 스탯은 **최소 1**, 최대 5다.

| 스탯 | 효과 | 공식 | 스탯 1 | 스탯 3 | 스탯 5 |
|---|---|---|---|---|---|
| **적재량** | 최대 적재 수 +1 / 1포인트 | `기본 적재 2 + (적재량 − 1)` | 2개 | 4개 | 6개 |
| **이동 속도** | 이동 속도 +20% / 1포인트 | `기본 속도 2.5 m/s × (1 + 0.2 × (이동 속도 − 1))` | 2.5 m/s | 3.5 m/s | 4.5 m/s |

- 기본 적재 2, 기본 속도 2.5 m/s, 집기 간격 0.25초는 `임시` 값이다. 작업 속도(지능) 스탯은 삭제했다.

**스탯 생성** `임시`
1. 스탯 총합을 2~8 중에서 뽑는다. 가중치 2:5 · 3:10 · 4:20 · 5:25 · 6:20 · 7:12 · 8:8 `확정` (가운데 값일수록 확률이 높음).
2. 두 스탯을 1로 두고 남은 포인트를 무작위로 나눠 준다 (스탯당 최대 5).
3. 고용금 = `스탯 총합 × 15`, 시급(파트마다) = `스탯 총합 × 4` → 좋은 알바일수록 비싸다.

### 11.3 역할 배치 `1순위`

- 역할은 3개(하차 · 분류 · 피킹)다. 고용하면 빈 역할에 자동 배정된다.
- 계약 PC 팝업의 **배치 탭**(`계약 | 고용 | 배치`)에서 언제든 역할을 바꾸거나 해고할 수 있다. 따로 두던 배치 현황판 게이지 존은 없앤다. `확정` (2026-11-11)
- 배치 탭은 하차 · 분류 · 피킹 **3열**이고 열 제목에 인원 수를 보여 준다. 알바 카드 = 역할 색 · `알바 N`(고용 순 번호, 미지급이면 옆에 붉은 `₩N 밀림`) · 스탯(이동 · 적재) · 시급.
- **카드를 다른 역할 열로 끌어다 놓으면 역할 변경**, 오른쪽 **해고 칸에 놓으면 확인 창**([해고] / [취소]). `확정` (2026-11-11)
- 역할을 바꾸면 들고 있던 화물은 원래 목적지에 배달을 끝낸 뒤 새 역할로 전환한다.

| 역할 | 작업 | 해금 | 대상이 없을 때 |
|---|---|---|---|
| **하차** | 입고 트럭 픽업 존 → 공용 보관소 | Lv.1 | 트럭 픽업 존의 빈 슬롯에서 대기 |
| **분류** | 공용 보관소(일반 상자만) → 빈자리가 있는 해당 품목 선반 적재 존 | Lv.1 | 팔레트 둘레의 빈 슬롯에서 대기 |
| **피킹** | 선반 → 출고 트럭 (피킹과 상차를 한 번에) | Lv.1 | 선반 둘레 존의 빈 슬롯에서 대기 |

### 11.4 작업 AI (상태 머신) `1순위`

```
대기 ──(작업 대상 발견 + 예약)──▶ 집으러 이동 ──▶ 집기 ──▶ 운반 ──▶ 내려놓기 ──┐
  ▲                                                                              │
  └──────────────────────────────(완료 / 대상 사라짐)────────────────────────────┘
```

- 작업 대상은 [8.4 수요 계산](#84-수요-계산)과 예약을 기준으로 고른다 (가까운 대상 우선).
- 집으러 가는 중에 대상이 사라지면 예약을 풀고 대기로 돌아간다.
- 알바의 이동 속도, 최대 적재 수, 집기 간격은 스탯으로 정해진다 → [11.2](#112-스탯-1순위)
- **작업 슬롯** `확정`: 작업 구역(존)마다 작업 지점 1~4개를 둔다. 알바는 **출발할 때** 빈 슬롯을 찾아 예약하고, 그 슬롯에서만 집고 내려놓는다. 빈 슬롯이 없으면 그 자리에서 멈춰 기다린다. 플레이어는 슬롯과 무관하게 존 근처 어디서나 작업한다. 슬롯은 화면에 표시하지 않는다.
  - 기본 수: 하차 존 2 · 상차 존 2 · 팔레트 둘레 4 · 선반 둘레 4 `임시`
- **대기** `확정`: 할 일이 없으면 [11.3](#113-역할-배치-1순위) 표의 대기 위치 (자기 역할 존의 빈 슬롯)에서 기다린다.

### 11.5 경로 탐색 `1순위`

- 네비메시로 목적지까지 이동한다. **알바끼리는 충돌하지 않고 겹쳐 지나간다** (회피 끄기).
- 플레이어와도 충돌하지 않는다 `확정`. **선반은 장애물이다** — 알바는 선반을 돌아가고, **플레이어도 선반에 막힌다** `확정`. 트럭은 주차 칸이 부지 밖이라 장애물로 두지 않는다.
- 부지 확장·시설 생성 시 네비메시를 런타임에 다시 굽는다.

### 11.6 대화 말풍선 `2순위` `확정`

- 가끔 알바 머리 위에 말풍선(이모지/짧은 대사)을 띄운다. 알바별 쿨타임 30초 `임시`, 화면 전체 동시 최대 2개.
- 대기 상태가 오래되면 "할 일이 없어요" 같은 말풍선으로 병목을 알려주는 용도로도 쓴다.
- 미지급 상태인 알바는 "월급 주세요" 말풍선을 더 자주 띄운다 (쿨타임 15초 `임시`).
- 애니메이션: `미소 짓기` / `당황하기` 등 이모션

### 11.7 파트 정산 · 시급 `1순위`

**파트** (→ [9.5](#95-저금통--파트-종료-정산-1순위))

- 시간은 **파트** 단위로 흐른다: 180초, 첫 파트만 90초 `임시`. 게임 시작(회사 A 계약 완료)부터 1파트가 시작된다.
- 팝업이 열려 게임이 일시정지된 동안에는 시간이 흐르지 않는다. 앱을 꺼둔 동안에도 흐르지 않는다 (오프라인 진행은 이후).
- 파트가 끝나면 **정산 팝업**: 출고 수입(저금통) + 할당량 보너스 − 알바 시급 = 합계 → 보유 재화. [확인]을 누르면 다음 파트.

**시급 정산** (파트 정산에 포함)

- 파트가 끝날 때 고용 중인 모든 알바의 시급을 정산 금액에서 차감한다. 고용한 파트는 **일한 시간 비율만큼만** 낸다: `시급 × 고용 때 파트 남은 시간 / 파트 길이`, **올림** `확정` (2026-11-11).
- 쓸 수 있는 돈 = 정산 금액 + 보유 재화. 모자라면 **고용 순서대로** `밀린 시급 + 이번 시급`을 지급하고, 지급하지 못한 알바는 미지급 처리한다 (부분 지급 없음). 앞 알바를 못 줘도 뒤 알바 몫이 되면 준다.

| 상태 | 조건 | 결과 |
|---|---|---|
| 정상 | 시급을 받음 | - |
| **미지급** | 정산 때 시급을 받지 못함 | 밀린 시급(= 이번 시급)을 기록. 머리 위 **빨간 ₩** 아이콘(위아래로 둥실), 배치 탭 카드에 `₩N 밀림` `확정`. "월급 주세요" 말풍선은 말풍선 작업 때. **작업은 계속한다** |
| **퇴사** | 미지급 상태에서 다음 정산 때 `밀린 시급 + 당일 시급`을 받지 못함 | 명단에서 바로 빠진다. 몸통이 **빨갛게 깜빡이며 제자리에서 두 번 점프**(`화내기` 애니메이션 대신, 모델이 나오면 교체) → 현재 운반을 끝내고 사무실 PC 앞으로 걸어 나가 사라진다. 고용금은 환불하지 않는다 `확정` |

- 밀린 시급은 **다음 정산 때 함께 계산**하고, 그때도 부족하면 퇴사한다. 미리 갚는 [밀린 시급 지급] 버튼은 두지 않는다 `확정` (2026-11-11).
- 정산 팝업: `알바 시급 −N`(실제로 낸 금액, 밀린 시급 포함) 줄 + 그 아래 작은 붉은 글자로 `미지급: 알바 3, 알바 5 — 다음 정산 때 못 받으면 떠납니다` / `퇴사: 알바 2`. 합계가 음수면 붉은색. `확정`
- 출퇴근 · 야간 작업은 이후로 미룬다.

### 12.2 주문서 큐 `1순위`

- 주문서는 상단 **오른쪽 끝부터** 쌓이고, 새 주문은 그 **왼쪽**에 붙는다 ([18번 확인 필요](#18-확인-필요-사항)).
- 화면에 보이는 슬롯은 5개 `임시`. 넘치는 주문은 왼쪽 끝에 `+n`으로 표시한다.
- 주문 카드 내용: 품목 색 아이콘 × 수량, 진행도, 상태 배지

| 상태 배지 | 의미 |
|---|---|
| 대기 | 아직 트럭이 배정되지 않음 |
| 🚚 도착 | 출고 트럭이 정차해 물건을 받는 중 |
| ✅ 출발 | 완료 연출 후 카드가 사라지고 나머지 카드가 오른쪽으로 당겨짐 |

- 배지는 아이콘 없이 **글자 + 색**으로 구분한다: 대기 회색 / 도착 파랑 / 출발 초록. `확정`
- 품목 줄은 `색 아이콘 실은 수/필요 수` (예: 빨강 `1/3`), 다 실은 줄은 초록 글자.

## 13. 튜토리얼

- 첫 플레이 시 아래 순서로 **바닥 유도선 + 화살표**를 띄워 안내한다. 각 단계는 조건을 만족하면 다음으로 넘어간다.
- 계약(1단계)은 진행에 반드시 필요하므로 `1순위`, 유도선·화살표 연출은 `2순위`.

| 단계 | 안내 | 완료 조건 |
|---|---|---|
안내 흐름: **사무실 → 하차 → 선반 → 상차 → 현금 줍기 → 첫 정산** `확정`

| 단계 | 안내 | 완료 조건 |
|---|---|---|
| 1 | (사무실에서 시작) 계약 PC → 회사 A 계약 | 계약 완료 (선반 2개 생성, 첫 입고 트럭 진입) |
| 2 | 하차장 트럭 뒷문 앞에서 화물 집기 → 팔레트에 내려놓기 | 팔레트에 화물 있음 |
| 3 | 팔레트에서 집어 선반에 넣기 | 선반에 화물 1개 이상 |
| 4 | 첫 주문서 등장 → 선반에서 꺼내 출고 트럭에 싣기 | 첫 출고 트럭 출발 |
| 5 | 현금 존에서 현금 줍기 → 저금통 | 저금통 금액 > 0 |
| 6 | 첫 파트 종료 → 정산 팝업 [확인] | 첫 정산 완료 (보유 재화 증가) |
| 7 | 계약 PC 고용 탭에서 도장을 찍어 알바 고용 (빈 역할 자동 배정) | 알바 1명 |

- 튜토리얼 중에는 첫 주문서를 4단계에 맞춰 1건만 생성한다. 첫 파트는 90초로 짧다.
- 7단계의 **첫 고용은 고용금 면제**다. 시급은 정상적으로 나간다.
- 첫 정산 때 미지급 · 퇴사 규칙을 1회 안내한다.
- Lv.4 복합 주문 시작 시 짧은 추가 안내(여러 품목을 한 트럭에)를 1회 띄운다.

## 14. 2순위 시스템

### 14.1 저장 / 불러오기

- 저장 항목: 레벨, XP, **보유 재화 · 저금통 금액 · 줍지 않은 현금(현금 존별)**, 해금된 구역 · 구매한 시설, 업그레이드 단계, 계약 상태, 알바 목록(**외형 · 스탯**, 시급, 역할, 미지급 금액), 파트 번호 · 남은 시간, 선반 · 공용 보관소 · 반품 롤테이너 재고, 주문 큐, 플레이어가 들고 있는 화물, 튜토리얼 진행도
- 저장하지 않는 것: 이동 중인 차량. 불러오면 차량은 새로 진입한다.
- 자동 저장: 레벨업, 구매·고용, 주문 완료 시 + 앱이 백그라운드로 갈 때

### 14.2 업그레이드

- 플레이어 적재량 / 이동 속도 (Lv.3), 선반 용량 (Lv.5, 논의 중), 공용 보관소 용량 (Lv.6). 수치는 [5.1](#51-기본-수치-임시), [9.4](#94-비용표-임시) 참고.
- 선반 용량 외형은 10 → 15 한 단계만 정해졌다 (나머지 논의 중).

### 14.3 돌발 이벤트 · 텐션 — 스케줄러 + 설비 고장 · 할당량 `확정`

- **할당량** `2순위`: 파트마다 목표 출고 대수, 달성 시 정산 보너스 (→ [9.5](#95-저금통--파트-종료-정산-1순위)).
- 이벤트는 파트 3번(약 9분)당 최대 2회, 이벤트 사이 최소 3분 `임시`, 동시 발생 최대 1건.
- **설비 고장** (Lv.5~): 하차장 또는 상차장 중 하나가 멈추고 연기·느낌표 아이콘이 뜬다. 플레이어가 가서 2초 `임시` 게이지 존에 서면 수리된다.
- 애니메이션: `당황하기`

### 14.4 코스튬 변경 — **삭제** `확정`

- 11/09 확정: 알바는 **갈아입히지 않는다**(입고 온 코스튬 그대로). 코스튬 뽑기 · 효과 · 시너지, 탈의실 · 옷장도 뺀다. 외형은 고용 때 랜덤으로 정해진다 (→ 11.1).

### 14.5 디버그 메뉴 · 테스트 도구 `2순위`

- 테스트용으로 재화 추가, 레벨업, 게임 배속(×1/×2/×4), 주문 즉시 생성, **파트 즉시 종료**, 레벨별 도달 시간 로그 표시 기능을 둔다.
- `임시` 수치를 빠르게 검증하는 데 필요하다.
