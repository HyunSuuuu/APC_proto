# 파라미터 전체 목록 (테이블 / 파라미터)

> GDD에 적힌 기능 **전부**(구현 안 된 것 포함)에서 기획이 정하는 값을 모았다. 이 목록 밖의 조정값은 없다는 전제로 쓴다.
> 기준: GDD 2026-11-17 (M13-10까지 구현). 값은 GDD 값, `임시` / `확정`은 GDD 표시 그대로.

---

## 0. 읽는 법

### 0.1 테이블 · 파라미터 정의

| 형식 | 뜻 | 예 |
|---|---|---|
| **테이블** | 기획자가 준 값이 **그대로 최종값**으로 코드에 들어간다 | 시작 돈 50 → 게임 시작 지갑 50 |
| **파라미터** | 공식에 들어가는 값. 바꾸면 **계산된 최종값이 바뀐다** | 고용금 계수 15 → 고용금 = 스탯 합계 × 15 |

- 값이 하나뿐인 항목도 "그대로 최종값"이면 테이블로 분류한다 (1장 끝 "단일 값" 표).
- 확률 · 가중치는 무작위 결과(최종값)를 정하는 입력이라 파라미터로 분류한다.

### 0.2 열

| 열 | 뜻 |
|---|---|
| 구현 | ✅ 게임에 들어가 있음 · ⬜ GDD에만 있음 (아직 안 만든 기능) |
| 위치 | 구현된 값이 들어 있는 설정 파일 (`Assets/Data`). **코드 상수** = 설정 파일이 없어 코드에 박혀 있음 (설정으로 빼야 함) |
| GDD | 근거 절 |

### 0.3 범위

- 넣음: GDD 3~14장의 모든 기능 (튜토리얼 · 황금 트럭 · 지게차 · 쓰레기 등 미구현 포함).
- 뺌: GDD 17장 백로그(프로토타입 이후), 삭제된 기능(저장 · 계약 · 검수 · 주문서 큐 · 코스튬 변경).
- 연출값(5장)은 기획 판단이 필요하면 쓰도록 따로 묶었다.

| 주문 색 최대 수 | 2 | `OrderService` (최대 2색 구조라 숫자 하나로 못 바꿈) |
| '넣을 수 없음' 재표시 간격 | 1.5초 | `CargoZone` |
| 팔레트 랙 용량 | 4 | `Module_ShelfArea_D.prefab` (`ShelfSlot.capacity`) |
| 작업 지점 수 | 2 · 2 · 4 · 4 · 1 | 모듈 프리팹 |
| 트럭 대기 자리 위치 · 간격 | 도로 x 0, 7m 간격 | `InboundQueue` (씬) |

## 5. 연출값 (참고)

**연출값** = 게임 규칙 · 밸런스에는 영향이 없고 **보이는 느낌만** 바꾸는 값 (애니메이션 시간, 튀는 크기, 흔들림 등). 기획 수치표에 넣을지는 총책임자 판단. 모두 ✅ 구현.

| 묶음 | 예 | 위치 |
|---|---|---|
| 상자 들기 | 날아가는 시간 0.25초 · 포물선 높이 1m · 들고 뛸 때 기울기 · MAX 글자 맥박 | `CarryConfig` |
| 돈 날아가기 | 저금통 아이콘까지 0.6초 · 곡선 높이 · 크기 그래프 · 다발 흡수 간격 0.05초 · 다발 비행 0.3초 | `CashFlyConfig` · `EconomyConfig` |
| 고용 도장 | 누를 때 1.25배 · 머무는 0.35초 · 자국 크기 · 실패 흔들림 | `StampConfig` |
| 트럭 | 하차 후진 2초 · 떠남 3초, 상차 후진 3초 · 떠남 1.5초 · 다음 상차 트럭 1초 | `LogisticsConfig` |
| 시설 | 모듈 · 건설 타일 팝 0.4초 · 레벨업 배너 약 2초 | `LogisticsConfig` · 코드 |
| 카메라 · 조작 | 감쇠 · 시야각 · 휠 줌 · 회전 속도 720도/초 | `ControlsConfig` · `PlayerConfig` |

> 트럭 시간 · 카메라는 플레이 체감(대기 시간)에 조금 영향을 주므로 경계에 있다. 1장에 넣을지 여기 둘지 정한다.
