## 1. 한눈에 보기

| 구분 | 직전 (변경사항 1) | 이번 업데이트 |
|---|---|---|
| 프로토타입 목표 | Lv.11 + 반품 재출고 | **Lv.5** [결정]. 문서에서는 'Lv.11' 언급이 모두 사라졌고 새 목표는 적혀 있지 않음 |
| 반품 구역 해방 | Lv.11 | **Lv.2** (임시) |
| 시트 구성 | 기능 리스트 · 프로토타입 이후 기능 · 저금통 설계 | **코스튬 · 애니메이션 · 에셋 · 기능 리스트**. 빠진 두 시트는 유효 [결정] |
| 기능 수 | 47개 (1순위 31 · 2순위 16) | **50개 (1순위 39 · 2순위 11)** |
| 시트 안 우선순위 기준 · 요약표 | 있음 | **없음** |
| 회의 결정 | 대부분 '-' | 대부분 **확정** |
| 핵심 신규 개념 | 계약 · 저금통 · 할당량 | **색 분류** (트럭 색 = 상자 색 = 보관 구역 색), **찌그러진 상자 · 쓰레기**, **알바 월급** |

### 핵심 루프 변경

```
직전  계약 → 하차 → 보관 → 상차 → 출고 현금 → 저금통 → 파트 종료 정산 → 구역 추가·고용 → Lv.11 반품

지금  레벨별 색 트럭 합류 → 하차 → 색 맞춰 보관 → 색상별 주문대로 상차 → 돈 더미 → 저금통
      → 파트타임 정산 (저금통 → 지갑, 알바 월급 지급) → 빈 구역 짓기 · 칸 늘리기 · 고용
      → Lv.2 반품 (찌그러진 상자 → 검수 → 재포장 → 재출고, 쓰레기 버리기) → … → Lv.5
```

- **계약이 없어지고** 레벨이 오르면 그 색 트럭이 웨이브에 자동으로 합류
- 상자를 아무 선반에나 두는 게 아니라 **같은 색 구역에만** 넣는 분류 플레이가 생김
- **경험치는 상차로 주지 않고** 시설 설치 · 빈 구역 완성 때만 줌
- 정산 때 **알바 월급이 나가고** 할당량 보너스는 없어짐. 돈은 여전히 **정산 후에만** 쓸 수 있음 [결정]

| 구매 / 해금 패드 (1) | **빈 구역 짓기 (건설 타일)** (1) | 열린 빈 구역의 건설 타일에 서 있으면 돈이 빠져나가며 게이지가 참 → 구역 생성 + **XP +3(임시)**. **돈이 모자라면 모인 만큼만 내고 나중에 이어서 냄** |
| 알바 외형 · 스탯 랜덤 생성 (2) | **알바 외형 랜덤 (코스튬)** (2) | **스탯 랜덤 삭제**. 대부분은 물류 유니폼이고, 일정 확률로 코스튬 알바가 나옴 (예: 마카롱 알바생). 하는 일은 같음. '코스튬 자랑하기' 애니메이션 연결 |
| 역할별 작업 루프 (1) | **직무별 작업 루프** (1) | 역할 → 직무. 직무는 **하차 · 상차 · 보관 · 반품** [결정]. 할 일이 없으면 자기 자리에서 대기. **플레이어는 알바를 직접 움직일 수 없음** |
| 역할 배치 (2) | **직무 배치** (2) | '직군별로 뽑을지 미정' → **뽑은 뒤 배치(임시)**. 논의 중 → **확정** |
| 재화 · 저금통 · 레벨 · 시간 표시 (1) | **돈 · 레벨 · 시간 표시** (1) | HUD 돈이 두 칸(보유 재화 / 저금통) → **지갑 한 칸**. '지갑'은 임시 이름이고 에셋에는 아직 안 넣을 예정 |

## 5. 이름은 같고 내용이 바뀐 기능

### 우선순위가 바뀜

| 기능명 | 우선순위 | 달라진 점 |
|---|---|---|
| 차량 대기열 | 2 → **1** | 하차 칸이 다 차면 건물 밖 도로에 줄 서서 대기. **최대 3대**, 줄이 차면 다음 트럭은 자리가 날 때까지 안 나옴. 에셋: 트럭 대기 자리 표시. 확정 |

### 동작 규칙이 바뀜

| 기능명 | 달라진 점 |
|---|---|
| 경험치 획득 | XP 지급: 출고 차량 출발 · 반품 재포장 · 시설 구매 · 알바 고용 → **시설 · 설비 설치, 빈 구역 완성 때만**. "상차는 안 줌". 확정 |
| 화물 종류 / 상태 | 종류 · 소속 회사 · 일반/반품 → **색(갈 · 초 · 파 · 주, 임시)** · **일반/찌그러짐**. 소속 회사 삭제. 크기는 **D 구역 가구 상자만 큼** [결정] |
| 화물 자동 집기 / 내려놓기 | **맨손은 최대 3개(임시)**. **상자와 쓰레기는 같이 못 듦**. 집는 곳이 하차 칸 '상자를 두는 공간', 상차 칸 '상자를 갖고 가는 공간'으로 바뀜 |
| 하차 화물 생성 | **하차 알바가** 트럭에서 꺼내 쌓음 (최대 10개, 임시). **꽉 차면 하차 알바가 기다리고 트럭도 못 떠남** |
| 선반 적재 / 꺼내기 | 구역마다 선반 4개(위치 고정). 1단계 선반 1개에 **6개** (기본 10 → 6, 구역당 24개). 가득 차면 그 색 상자는 하차 구역에서 더 못 옮김 |
| 상차 적재 → 출고 | 상차 패드 → 상차 칸. 빈 칸에 트럭이 바로 들어옴 → 트렁크 문 열림 → **상차 알바가** 싣고, 다 차면 문을 닫고 **돈을 두고 떠남** → 다음 트럭 바로 진입. 출발 때 XP 지급 문구 삭제 |
| 반품 접수 · 검수 | **Lv.11 → Lv.2(임시)**. 찌그러진 상자를 **반품 선반**에 둠 → 검수 테이블에서 검사(고민하는 몸짓). 반품 선반이 꽉 차면 찌그러진 상자는 하차 구역 바닥에 남음. 롤테이너 · 스캐너 · 바코드 스캔 삭제 |
| 재포장 → 재출고 | 재포장 작업대 → **포장대**(우당탕탕 먼지). 재포장 상자는 상자 보관 선반으로. **하다 멈추면 돌아와서 이어서 함**. **반품 알바가 없으면 플레이어가 직접** |
| 사무실 투명 저금통 | 동전 10단계 → **지폐 3단계(임시)** [결정: 지폐]. 정산 시 비워져 **지갑(UI)으로 이동**. 꽉 차도 돈은 계속 모이고 모습만 더 안 차오름 |
| 상호작용 존 감지 | 대상이 **클립보드 책상 · 컴퓨터 책상** · 건설 타일 · 검수 테이블 · 포장대 · 돈 더미로 바뀜. **책상 앞에서는 메뉴가 열리고**, 건설 타일에서만 게이지가 참 |
| 적재량 · 이동 속도 업그레이드 | 업그레이드 패드 → **사무실 컴퓨터 책상** (Lv.2, 임시). 확정 |
| 알바 고용 | 고용 데스크 → **클립보드 책상**. 고용하면 사무실에서 나와 맡은 자리로 감. **돈이 모자라면 버튼 회색, 최대 인원이면 고용 불가**. '빈 역할 자동 배정' 문구 삭제 |
| 알바 해고 | 해고 장소가 **클립보드 책상**으로 정해짐 |
| 구역 추가 | '해금하면 통째로 생김' → **지으면 생김**. '지역(맵)은 1개' 문구 삭제. 에셋에 복도 바닥 추가 |
| 자유 이동 (플레이어와 분리) | 드래그 → **UI 버튼으로 플레이어 고정을 풀고** 한 손가락으로 둘러보기, 두 손가락으로 확대 · 축소. 같은 UI를 다시 누르면 복귀. 'CCTV 만들지 않음' 문구 삭제 |
| 정산 팝업 | 출고 수입 · 반품 재출고 수입 · 할당량 보너스 · 합계 → **번 돈 · 알바 월급 · 합계** |
| 레벨업 팝업 | 안내 항목에 **새 트럭 색 합류** 포함. 만세 환호 애니메이션 삭제 |
| 튜토리얼 가이드 | 흐름 '사무실 → 하차 → 선반 → 상차 → 현금 줍기 → 첫 정산' → **'하차 → 선반 → 상차 → 돈 줍기 → 사무실 → 반품 구역'**, **Lv.2 반품 구역에서 끝**. 회의 결정 → 논의 중. 안내 방식은 **카메라 이동 · 확대 강조** [결정] |

### 분류 · 회의 결정만 바뀜

- 대분류 `플레이어` → **`플레이어 관련 (UI 섞임)`**
- 물류 흐름 중분류: `계약` 삭제, **`하차 트럭`** · **`쓰레기`** 추가 (차량 대기열은 `하차` → `하차 트럭`으로 이동)
- '-' → **확정**: 가상 조이스틱 이동, 경로 탐색 (위 표에 적은 기능 말고)

| **황금 트럭 · 금** | Lv.1 | 하차 트럭 중 **0.05% 확률**로 등장. 하차 칸에 **금 오브젝트**를 쌓고 감. 금 1덩이 = 일반 돈의 **2배**. **플레이어만** 주울 수 있음 (임시). 멀리서도 알 수 있게 반짝이고, 트렁크 문이 열릴 때 금이 쏟아지는 연출 | 결정 10 · 에셋 리스트 |
