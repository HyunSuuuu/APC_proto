# 앙팡물류센터 — 구현 체크리스트

> 기준 문서: [GDD.md](GDD.md) v0.2 · [TechStack.md](TechStack.md)
> 체크 방법: 작업이 끝나면 `- [ ]` → `- [x]`. 마일스톤의 **완료 확인**을 실제 플레이로 통과해야 다음 마일스톤으로 넘어간다.

## 진행 순서

```
M0 기반 ─▶ M1 이동·카메라 ─▶ M2 운반 코어 ─▶ M3 입고·보관 ─▶ M4 주문·수익 ★첫 플레이어블
                                                                   │
        ┌──────────────────────────────────────────────────────────┘
        ▼
M5 성장·확장 ─▶ M6 알바 ─▶ M7 포장·복합 주문 ─▶ M8 Lv.1~11 콘텐츠 ─▶ M9 반품 ★1순위 완료
                                                                          │
                                                                          ▼
                                                                    M10 2순위
```

| 마일스톤 | 목표 | 우선순위 | 완료하면 확인할 수 있는 것 (GDD 1.4 검증 질문) |
|---|---|---|---|
| M0 | 프로젝트 기반 | 1 | - |
| M1 | 이동 · 카메라 | 1 | - |
| M2 | 운반 코어 | 1 | Q1 운반 손맛 |
| M3 | 입고 · 분류 보관 | 1 | Q2 흐름 이해도 (일부) |
| **M4** | **주문 · 수익 — 혼자서 1사이클** | 1 | **첫 플레이어블.** Q2 흐름 이해도 |
| M5 | 성장 · 부지 확장 | 1 | Q5 성장 속도 (초반) |
| M6 | 알바 (하차 · 분류 · 피킹) | 1 | Q3 자동화 쾌감, Q6 스탯·시급 |
| M7 | 포장 · 복합 주문 (Lv.4) | 1 | Q4 난이도 상승 |
| M8 | Lv.1~11 콘텐츠 배치 | 1 | Q5 성장 속도 (전체) |
| **M9** | **반품 (Lv.11)** | 1 | **1순위 완료 — Lv.1~11 끝까지 플레이 가능** |
| M10 | 2순위 기능 | 2 | 완성도 |

### 이 순서인 이유

1. **손맛을 가장 먼저 검증한다 (M1~M2).** 자동 집기·스택 연출이 재미없으면 그 위에 쌓는 모든 시스템이 의미가 없다. 박스 몇 개와 선반 하나만으로 바로 검증할 수 있다.
2. **돈이 들어오는 1사이클을 최대한 빨리 완성한다 (M3~M4).** 혼자서 하차 → 분류 → 피킹 → 상차 → 현금까지 돌아가야 이후 시스템(성장, 알바)을 붙였을 때 효과를 체감할 수 있다.
3. **성장(M5)을 알바(M6)보다 먼저 만든다.** 알바 고용은 구매 패드, 재화, 최대 인원(레벨) 위에서 동작한다. 부지 확장은 네비메시 재굽기와 묶여 있어서 알바 전에 구조를 잡아 두는 편이 낫다.
4. **알바(M6)를 포장(M7)보다 먼저 만든다.** 튜토리얼상 알바는 Lv.1, 포장은 Lv.4에 나온다. 하차·분류·피킹 역할은 포장 없이 동작한다.
5. **반품(M9)은 마지막이다.** Lv.11 전용이고, 다른 시스템을 모두 재사용한다.
6. **디버그 메뉴는 M0에서 만들고 계속 늘린다.** 재화·레벨·배속 치트가 없으면 M5 이후 테스트가 너무 느려진다.

### 공통 원칙

- 아트는 **임시 프리미티브**로 진행한다. 단, 테이프 색(품목 구분)은 처음부터 적용한다.
- 수치는 처음부터 **ScriptableObject**에서 읽는다 (코드에 숫자를 쓰지 않는다).
- 플레이어와 알바가 **같은 운반 컴포넌트**를 쓰게 만든다 (M2에서 설계 → M6에서 재사용).

- [x] **M3-4 트럭 픽업 존** — 트럭에서 꺼낸 화물은 공용 보관소에만 놓을 수 있음
- [x] **M3-5 계약 PC · 계약 팝업** — 게이지 존 → 팝업(회사, 품목, 물량, [계약]) → 회사 A 선반 4개 팝 생성 + 입고 시작
  - 팝업 중 게임 정지(timeScale 0). 계약하면 팝업이 닫히고 선반이 생김. 회사 B는 `Lv.7 해금` 잠금
  - 멈추고 0.5초 뒤 팝업 (게이지 존은 별도 대기 없이 게이지가 곧 대기). 버튼은 화면 레이캐스트 → 클릭 경로로 확인
- [x] **M3-6 시설 팝 연출** — DOTween 크기 펀치 (선반, 이후 모든 시설이 공용으로 사용)
  - `FacilityPop.Play(transform)`

> **부지 = 모듈 조립** (TechStack 5.7). 메뉴 `APC > Setup > Build Site`가 `SiteLayout`(config)대로 시작 모듈을 씬에 굽고 잠긴 칸은 잠김 표시로 둔다. 해금은 실행 중 `SiteGrid.Unlock(id)` (디버그 메뉴 Site 버튼으로 테스트). 모듈 내용은 씬이 아니라 `Assets/Prefabs/Modules`의 프리팹에서 고친다.

**완료 확인**: 계약하면 트럭이 들어오고, 트럭 → 공용 보관소 → 색깔별 선반으로 직접 나를 수 있다.

## M5. 성장 · 부지 확장 (GDD 4, 9.2~9.4, 10)

- [ ] **M5-1 XP · 레벨** — 주문 완료·구매 시 XP, 레벨 테이블 데이터, 좌상단 레벨/XP 바
- [ ] **M5-2 해금 시스템** — 레벨업 시 해금 테이블 조회 → 대상 패드·칸을 '열림'으로, 다음 레벨 항목은 반투명 잠금(`Lv.N`) 표시
- [ ] **M5-3 구매/해금 패드** — 아이콘 + 비용 + 게이지 링, 1.5초 동안 재화 투입, 부족하면 멈춤·유지, 완료 시 시설 생성
- [ ] **M5-4 부지 그리드 · 확장 칸** — 그리드 데이터(GDD 4.2), 인접 칸만 해금, 바닥·벽 모듈 이어 붙이기 연출, 사이 벽 제거
- [ ] **M5-5 네비메시 런타임 재굽기** — 확장·시설 생성 시 `NavMeshSurface` 갱신 (M6 알바 대비)
- [ ] **M5-6 레벨업 연출 v1** — 축하 이펙트 + 간단한 해금 안내 (팝업 디자인은 M10)
- [ ] **M5-7 사무실 구역** — 시작 부지에 사무실 배치 (계약 PC 이동, 고용 데스크·배치 현황판 자리 확보)

**완료 확인 (Q5 초반)**: Lv.1 → Lv.3까지 플레이하며 확장 칸 E1·E5를 구매할 수 있다. 레벨업 간격이 너무 빠르거나 느리지 않은지 기록한다.

## M6. 알바 (GDD 11)

- [ ] **M6-1 알바 기본** — NavMeshAgent + M2 운반 스택 재사용, 회피 끄기(겹쳐 지나감), 걷기/들고 걷기 애니메이션
- [ ] **M6-2 스탯 · 파생값** — 힘/민첩/지능 → 적재 수, 이동 속도, 작업 배율 (GDD 11.2 공식), 스탯 생성 규칙(총합 4~9)
- [ ] **M6-3 작업 상태 머신 기반** — 대기 → 대상 탐색·예약 → 집으러 이동 → 집기 → 운반 → 내려놓기, 대상이 사라지면 예약 해제
- [ ] **M6-4 역할: 하차 · 분류 · 피킹** — 역할별 작업 대상 규칙, 대기 위치
- [ ] **M6-5 고용 데스크 · 이력서 UI** — 후보 3명(이름, 스탯, 효과, 고용금, 시급), 고용 → 문 앞 생성, 고용한 자리는 빈칸, 최대 인원 MAX
- [ ] **M6-6 이력서 갱신** — 10분 자동 갱신(하루 시작 시점) + 타이머 표시, 유료 새로고침(`20 × 레벨`)
- [ ] **M6-7 배치 현황판 UI** — 알바 목록(역할, 스탯, 시급, 미지급), 역할 변경, 고용 직후 자동으로 열림
- [ ] **M6-8 하루 타이머** — 10분, 일시정지 중 멈춤, HUD 일차·시계
- [ ] **M6-9 시급 정산** — 하루 끝에 지급(첫날 비례), 고용 순서대로 지급, 미지급 → 💸 상태, 두 번째 미지급 → 퇴사(운반 마치고 퇴장)
- [ ] **M6-10 정산 결과 팝업 · 밀린 시급 지급** — 총 지급액, 미지급·퇴사 알바, 경고 / 배치 현황판에서 미리 지급

**완료 확인 (Q3, Q6)**: 알바 3명(하차·분류·피킹)만 두고 손을 놓아도 사이클이 돌아간다. 알바끼리 같은 화물을 두고 경쟁하지 않는다. 시급 때문에 일부러 재화를 비우면 미지급 → 퇴사가 규칙대로 동작한다.

## M7. 포장 · 복합 주문 — Lv.4 (GDD 7.5, 8.1, 8.5)
