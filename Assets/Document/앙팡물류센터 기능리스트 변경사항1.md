# 앙팡물류센터 기능 리스트 — 변경사항 1

> 이전 문서(11/05 XMind 기준)와 업데이트 문서(11/09 기획 발표 기준)의 **기능 리스트**를 비교한 문서
> 띄어쓰기·가운뎃점(`·`) 정리 같은 표기 변경은 빼고, 내용이 달라진 것만 적음

> 업데이트 파일에는 코스튬 · 애니메이션 · 에셋 리스트 시트가 들어 있지 않음. 이 시트들은 이번 비교에서 뺐음.

### 핵심 루프 변경

```
이전  하차 → 보관 → 상차 → 현금 → 건설·고용
지금  계약 → 하차 → 보관 → 상차 → 출고 현금 → 저금통 → 파트 종료 정산 → 구역 추가·고용 → Lv.11 반품
```

- **계약**이 루프 맨 앞에 들어감 (계약해야 차량이 들어옴)
- 현금이 바로 쓰는 돈이 아니라 **저금통 → 파트 종료 정산**을 거쳐야 쓸 수 있게 바뀜
- **반품 재출고**가 프로토타입의 마지막 목표가 됨
- 지난번에 짚었던 *"루프에 꼭 필요한데 3순위였던 기능"*(현금, 구매 패드, 경험치, 레벨업, 시간 흐름)이 **전부 1순위로 올라감**

### 우선순위 기준 변경

| 우선순위 | 이전 | 업데이트 |
|---|---|---|
| 1순위 | 핵심 루프에 꼭 필요한 기능 | Lv.11 프로토타입에 **무조건** 필요. 없으면 위 흐름이 끊김 |
| 2순위 | 저장, 업그레이드, 가이드, 일부 이벤트 | 저장, 업그레이드, 가이드, **할당량 · 이벤트 1종, 테스트 도구** |
| 3순위 | 프로토타입 이후 또는 미정 | **이 시트에서 빠지고** `프로토타입 이후 기능` 시트로 옮김 |

## 3. 바뀌거나 쪼개진 기능

| 이전 기능 (우선순위) | → 업데이트 기능 (우선순위) | 달라진 점 |
|---|---|---|
| 시간 흐름 (하루 / 파트) (3) | **시간 흐름 (파트)** (**1**) | 파트 길이 고정(예: 3분), 첫 파트만 짧게(예: 90초). 출퇴근 기반 문구 빠짐. 논의 중 → **확정** |
| 사무실은 걸어서 이동 (3) | **사무실 스폰 · 걸어서 이동** (**1**) | 사무실 = 최초 스폰 지점. 화살표 안내는 별도 기능으로 분리 |
| 현금 생성 · 수거 (3) | **출고 현금 생성 (현금 더미)** (**1**)<br>**현금 수거 → 저금통** (**1**) | 둘로 쪼갬. 출고 차량이 **출발하는 순간** `실린 화물 수 × 계약 단가`만큼 현금 존에 지폐가 쌓임. 주운 돈은 바로 쓰지 않고 저금통으로. 줍지 못한 돈은 다음 파트로 넘어감. 알바는 줍지 않음 |

| 재포장 / 폐기 분기 (3) | **재포장 → 재출고** (**1**)<br>폐기 분기 (3, 이후 시트) | 재포장은 1순위로 올림. 재포장된 반품은 상차 패드로 일반 화물처럼 출고. 폐기는 이후로 미룸 |

## 7. 새 시트: 저금통 설계

출고 현금 → 사무실 투명 저금통 → 파트 종료 정산 구조의 상세 설계. 수치는 전부 제안값이에요.

**돈 흐름**

1. 출고 차량 출발 → 현금 존에 지폐 다발 생성 (`현금 존 금액 += 실린 화물 수 × 계약 단가`)
2. 현금 존에 쌓임 (최대 40개까지 보이고, 넘으면 맨 위에 '+금액' 숫자). 줍지 않아도 사라지지 않음
3. 플레이어가 들어가면 수거 → 저금통 금액 증가
4. 돈을 쓸 때는 **보유 재화만** 줄어듦 (저금통 돈은 못 씀)
5. 파트 종료 → `보유 재화 += 저금통 + 할당량 보너스`, 저금통 = 0
6. 남은 현금 존 돈은 다음 파트로 넘어감

**주요 파라미터 (제안값)**

| key | 값 | 설명 |
|---|---|---|
| `part_length_sec` | 180 | 파트 길이(초) |
| `first_part_length_sec` | 90 | 첫 파트만 짧게 |
| `start_money` | 50 | 시작 보유 재화 (선반 1개 정도) |
| `cash_bundle_value` | 10 | 지폐 다발 1개 금액 |
| `cash_pile_cols` × `rows` × `layers` | 4 × 5 × 2 | 보이는 다발 최대 40개 |
| `collect_radius` | 1.5 | 수거 시작 거리 (m) |
| `piggy_step_count` | 10 | 저금통 높이 단계 |
| `piggy_full_min` / `piggy_full_ratio` | 300 / 1.2 | 가득 기준 = `MAX(300, 직전 파트 정산액 × 1.2)` |

**구현 메모 요약**

- `MoneyManager`에 `wallet`(보유 재화)과 `piggy`(저금통) 두 값. 이벤트는 `OnWalletChanged` / `OnPiggyChanged`
- `CashZone` 컴포넌트 = 현금 존 1곳. 남은 금액만 들고, 다발은 오브젝트 풀(40개)에서 꺼내 씀
- `Settle()`: 할당량 판정 → `wallet += piggy + bonus` → 정산액 저장 → `piggy = 0` → 팝업
- 다발 이동은 포물선 트윈(DOTween `DOJump` 같은 것)

**새로 필요한 에셋 · 연출**: 투명 저금통, 동전 더미 10단계, 지폐 다발 (이상 1순위) / 동전, 현금 존 바닥 마킹, 수거·정산 소리 (2순위) / 다발 튀어나오기·빨려오기, 정산 연출, 정산 팝업, HUD 돈 두 칸 (1순위)
